# sandbox/latex

Image build LaTeX: TeX Live cố định, latexmk, pdfLaTeX/XeLaTeX + natbib; chạy dưới gVisor, không mạng, giới hạn 120 s / 2 GB (kiến trúc 9, ADR-11). Dockerfile viết sau khi SPK-06 có kết quả.
