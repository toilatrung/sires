# kubernetes

Giao diện cụm Kubernetes. `cluster` mô tả tên và phiên bản mong muốn. `cluster_version = null` để môi trường chưa cần cam kết phiên bản.

Phần cấp phát tài nguyên chờ quyết định AQ-12.
