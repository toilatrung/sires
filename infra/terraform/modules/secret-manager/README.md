# secret-manager

Giao diện secret manager. `secret_names` là tập tên logic để tham chiếu secret. Giá trị của secret do luồng triển khai nạp vào secret manager sau AQ-12.

Phần cấp phát tài nguyên chờ quyết định AQ-12.
