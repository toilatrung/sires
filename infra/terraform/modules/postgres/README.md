# postgres

Giao diện PostgreSQL. Mỗi khóa trong `service_extensions` tạo một mục database logic `sires_<service>`, với dấu gạch ngang đổi thành gạch dưới. Danh sách mặc định theo DDL. Ba extension của `00-common.sql` được hợp nhất với phần bổ sung của từng service, gồm `vector` cho knowledge.

Phần cấp phát tài nguyên chờ quyết định AQ-12.
