SIRes — Thiết kế kiến trúc hệ thống (MVP)

Suy ra từ PRD SIRes v1.0 (PO duyệt qua phiếu chốt PC-01, 31/10/2026) và API 0.1.0-mvp · Khởi tạo: 31/10/2026 · Phiên bản 0.2: tách backend thành nhiều service theo chỉ đạo ngày 31/10/2026

Tài liệu mô tả cách hiện thực SIRes: technology stack, các service và ranh giới dữ liệu, luồng hoạt động giữa service, và phương án cho các bài toán kỹ thuật mà PRD đặt ra — workflow dài bền vững, điều phối đa agent độc lập provider, RAG có cách ly, sandbox build LaTeX, bảo vệ API key, khôi phục sau gián đoạn, nhất quán xuyên service. Đối tượng: SWE, GEN AI, AIE, coding agents và QA. Quy ước biên soạn: README.md.

Trạng thái quyết định (31/10/2026). Đã chốt: backend chia nhiều service; service hệ thống dùng TypeScript/NestJS, agent core dùng Python; monorepo chung FE + BE; các đề xuất còn lại của technology stack bản 0.1 (ADR-03–ADR-16) được chấp thuận. knowledge là service Python riêng (ADR-18). Còn ở trạng thái Proposed: danh sách service cụ thể, RabbitMQ, hợp đồng nội bộ, công cụ monorepo, database theo service, audit tập trung (ADR-17, ADR-19–ADR-23, sổ ADR). Khi tài liệu này khác PRD hoặc đặc tả API, PRD và API là chuẩn.
