Làm

  1. Component Agent List dùng trong ProjectActivity (bên phải) và chi tiết workflow, theo AgentList: tiêu đề “Agents”, câu tóm tắt (số đang chạy, chờ bạn, lỗi, gián đoạn, đang rảnh), phạm vi (project, giờ); đủ 10 dòng: Orchestrator, Discovery, Reference Processing, Evidence Retrieval, Synthesis, Writing, Verification, Diagram, Analysis Agent A, Analysis Agent B; mỗi dòng: vòng tròn chữ viết tắt, tên và vai trò (listAgents), chip, liên kết Task và bước khi không rảnh.
  2. Trạng thái mỗi agent (EC30) từ workflow đang hoạt động của project (listWorkflows với projectId, trạng thái Running, Waiting for User, Paused, Interrupted; bước hiện tại và assignedAgent; Agent Run Failed của bước): bước Waiting for User → Chờ bạn; Agent Run Failed hoặc kết nối hiệu lực Invalid (listAgentModelAssignments và listProviderConnections, EC31) → Lỗi; workflow Interrupted → Gián đoạn; bước Running → Đang chạy; còn lại Đang rảnh. Nhiều việc thì lấy việc khẩn nhất: Chờ bạn > Lỗi > Gián đoạn > Đang chạy > Đang rảnh.
  3. Nhãn trạng thái agent theo ngôn ngữ giao diện (EN: Running, Needs you, Interrupted, Error, Idle), mỗi nhãn đúng một kiểu của design.md §3 (EC32); chấm Đang chạy theo 2.4.1.
  4. Token sáng; biến thể tối chỉ qua [data-theme="dark"] của token (design.md §2.1), không thêm công tắc. Cập nhật theo SSE như S02.
