Làm

  1. Khung Agent Run (mở từ bước hoặc ?agentRun= trên URL trang workflow): getAgentRun; agent (Analysis A, B theo instance), Provider Connection (tên từ listProviderConnections) và model thực tế, context đầu vào (inputSummary, contextManifest: entity theo version, phần bị cắt), công cụ (toolCalls), đầu ra (outputRefs liên kết, structuredOutput dạng khóa–giá trị rút gọn), usage, thời gian (startedAt–endedAt), attempts, lỗi (mã 8.6, không hiện nguyên văn của provider), nhãn discarded (EC22, EC24). Không có trường hay giá trị API key; câu “Không hiển thị suy luận nội bộ của model và không hiển thị API key”.
  2. Debug (EC23): hasDebugTranscript sai → “Không lưu toàn văn (chế độ debug tắt)”; đúng → phần “Toàn văn prompt/phản hồi (debug)” thu gọn kèm ngày tự xóa, mở thì gọi getAgentRunDebugTranscript; 404 → “Toàn văn đã hết hạn hoặc không còn”. Nội dung hiện dạng chữ trong khối cuộn.
  3. Usage (H14): token in, token out, số lời gọi; noData → “không có dữ liệu”, null → “—” (EC25); tổng của workflow ở đầu trang workflow = tổng chính xác qua listAgentRuns (EC26); chi phí chỉ khi có usage.extra.cost, kèm đơn vị và nhãn “ước tính” (EC27); không có cảnh báo, giới hạn ngân sách (EC28).
  4. Route /projects/:projectId/activity/agent-runs/:agentRunId: getAgentRun → chuyển tới /projects/:projectId/activity/workflows/:workflowId?agentRun= mã; 404 → “không tìm thấy” (EC29). Là đích liên kết Agent Run của Chat (PID-00058 H8).
  5. Không có Agent Run: trạng thái trống có lý do (EC21).
