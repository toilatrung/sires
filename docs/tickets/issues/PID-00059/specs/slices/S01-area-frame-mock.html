Làm

  1. Đọc docs/ui-design/design.md (§2.4, 2.4.1, §3, §4), sáu màn tham chiếu và trang trạng thái, designs/notes.html, README của shell và README mock của PID-00013.
  2. apps/web/src/features/monitoring/index.tsx: route thật activity, projects/:projectId/activity, projects/:projectId/activity/workflows/:workflowId, projects/:projectId/activity/agent-runs/:agentRunId (H13), projects/:projectId/history qua hợp đồng Feature. Bảng route ở apps/web/README.md là file chung: báo phiên điều phối thêm dòng route mới, không tự sửa.
  3. Namespace monitoring trong apps/web/src/features/monitoring/i18n/vi.json, en.json: mọi chuỗi; tên trạng thái entity giữ tiếng Anh; nhãn trạng thái agent của Agent List theo ngôn ngữ (design.md §3). Không còn chuỗi cứng.
  4. Mock trong apps/web/src/features/monitoring/__mocks__/: override có trạng thái cho 10 operation của khu vực: listWorkflows, getWorkflow, pauseWorkflow, resumeWorkflow, cancelWorkflow, decideWorkflowRecovery, listAgentRuns, getAgentRun, getAgentRunDebugTranscript, listProjectAuditEvents (H6). Lệnh đổi trạng thái theo 18.2 (lệnh không hợp lệ trả 409 invalid_transition) và phát workflow.status_changed, agent_run.status_changed qua mock /events của PID-00013. Operation của khu vực khác dùng mock đã ghép khi chạy dev, override cục bộ trong test.
  5. Fixture theo màn tham chiếu (wf-52d T-2.3 năm bước; workflow ở đủ tám trạng thái; Agent Run có và không có debug; audit event của bốn loại actor). Không có key hay host thật.
  6. Đang tải, trống, lỗi bằng component của shell (EC37).
