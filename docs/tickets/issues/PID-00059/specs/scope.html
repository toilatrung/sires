Edge case

Quét theo nhóm áp dụng cho monitoring: dữ liệu rỗng và biên (chưa có workflow, không có Agent Run, nhiều trang); thời gian và chạy lâu (workflow Running, thời gian chạy, Agent Run đang chạy); đồng thời (bấm hai lần, 409 invalid_transition, sự kiện đến khi đang gửi lệnh); trạng thái (đủ tám trạng thái workflow theo 18.2, Interrupted, Paused từ Waiting for User, kết thúc chỉ xem); sự kiện (trùng, sai thứ tự, mất, nối lại); provider (lỗi trên Agent Run, kết nối Invalid); provenance (actor, Agent Run của bước, đầu vào và đầu ra theo version); giao diện (trống, đang tải, lỗi, 390 px, vi/en, reduced motion); nội dung nguy hiểm (API key, suy luận nội bộ, HTML trong tóm tắt). Migration không áp dụng.
