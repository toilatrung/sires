S01 — Outbox trong giao dịch và relay

Nội dung
  • Làm
  • Kiểm
  • Xong khi

Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

ACPID-00002-AC06
Output specO1, O6, O10 (phần lease)
Bước specB1
Edge caseEC01, EC02, EC03, EC04, EC05, EC06 (từ specs/scope.html)
Phụ thuộcPID-00001 (helper giao dịch, UUIDv7, trace); hợp đồng theo H2 đã vào main

Làm

  1. Thêm amqplib (hoặc client AMQP tương đương có publisher confirm) và testcontainers vào libs/ts/platform/package.json
  2. Viết API ghi outbox dùng giao dịch của helper tenancy: event, audit bắt buộc aggregate {type, id, version} (H2), command không bắt buộc; dựng payload theo EventEnvelope; id UUIDv7; lấy traceparent hiện hành
  3. Viết hàm tính routing key theo AsyncAPI: sự kiện đổi trạng thái thêm đoạn con là trạng thái đích viết thường, khoảng trắng thành _
  4. Viết lease trong libs/ts/platform/src/jobs/: INSERT … ON CONFLICT (name) DO UPDATE … WHERE job_lock.lease_until < now(), gia hạn khi đang chạy (database 9.4)
  5. Viết relay chạy bằng vai trò _system: lô WHERE published_at IS NULL ORDER BY created_at FOR UPDATE SKIP LOCKED; event, audit tới sires.events, command tới queue cùng tên; deliveryMode 2, header message_id, traceparent; đặt published_at sau confirm
  6. Test dùng Testcontainers với PostgreSQL 16 + pgvector (nạp docs/database/ddl/00-common.sql, tạo vai trò _app, _system) và RabbitMQ

Kiểm

  • pnpm nx run @sires/platform:test → đạt
  • libs/ts/platform/src/outbox/outbox.spec.ts › relay publish có confirm (PID-00002-AC06)
  • libs/ts/platform/src/outbox/outbox.spec.ts › phát lại sau khi relay dừng (EC01)
  • libs/ts/platform/src/outbox/outbox.spec.ts › chỉ một relay giữ lease (EC02)
  • libs/ts/platform/src/outbox/outbox.spec.ts › broker không xác nhận (EC03)
  • libs/ts/platform/src/outbox/outbox.spec.ts › routing key trạng thái đích (EC04)
  • libs/ts/platform/src/outbox/outbox.spec.ts › thiếu aggregate (EC05)
  • libs/ts/platform/src/outbox/outbox.spec.ts › lệnh tới queue (EC06)

Xong khi

  • API ghi outbox, relay, lease xuất qua libs/ts/platform/src/index.ts
