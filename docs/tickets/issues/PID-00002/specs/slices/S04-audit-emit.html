S04 — audit-emit qua outbox

Nội dung
  • Làm
  • Kiểm
  • Xong khi

Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

ACPID-00002-AC01, DATA-PERSIST-001-AC01, NFR-DUR-001-AC01, CTX-AUDIT-001-AC01, CTX-AUDIT-001-AC02, CTX-AUDIT-001-AC03, CTX-AUDIT-001-AC04
Output specO4, O5, O9
Bước specB4
Edge caseEC16, EC17 (từ specs/scope.html)
Phụ thuộcS01

Làm

  1. Viết audit-emit: nhận actor, action, objectType, objectId, objectVersion, fromState, toState, apr, summary; dựng AuditEvent với id UUIDv7, accountId, projectId từ ngữ cảnh, correlationId = trace id, at
  2. Ghi một dòng outbox audit, routing key audit.recorded, id dòng = id Audit Event, trong cùng giao dịch với thay đổi (dùng API của S01)
  3. Kiểm actor theo CTX-AUDIT-001: Researcher có accountId; agent có tên agent và agentRunId; System có thành phần
  4. Che chuỗi giống key trong summary bằng bộ che của PID-00001
  5. Điền aggregate = {type: audit_event, id: id Audit Event (= id dòng outbox), version: 1} (H3); service gọi không truyền thêm gì

Kiểm

  • pnpm nx run @sires/platform:test → đạt
  • libs/ts/platform/src/audit/audit.spec.ts › rollback không để lại outbox và Audit Event (PID-00002-AC01, DATA-PERSIST-001-AC01, NFR-DUR-001-AC01)
  • libs/ts/platform/src/audit/audit.spec.ts › đủ trường AuditEvent (CTX-AUDIT-001-AC01)
  • libs/ts/platform/src/audit/audit.spec.ts › aggregate là chính Audit Event (H3, P6)
  • libs/ts/platform/src/audit/audit.spec.ts › actor không hợp lệ (EC16, CTX-AUDIT-001-AC02)
  • libs/ts/platform/src/audit/audit.spec.ts › che key trong summary (EC17, CTX-AUDIT-001-AC03)

CTX-AUDIT-001-AC04: ghi trong report.md danh sách API xuất từ libs/ts/platform/src/audit/, không có hàm sửa hay xóa.

Xong khi

  • Mọi AC và EC của slice đạt; aggregate điền theo H3
  • audit-emit xuất qua libs/ts/platform/src/index.ts
