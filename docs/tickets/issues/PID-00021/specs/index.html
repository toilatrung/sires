4.4. Quy tắc và trạng thái

  • Báo PO để nhận key; giữ key trong biến môi trường cục bộ
  • Với mỗi provider: tool calling, structured output cùng một schema, streaming, usage
  • Base URL tùy chỉnh qua proxy cục bộ chuyển tiếp tới endpoint chính thức
  • Gây lỗi có chủ đích: key sai, vượt giới hạn, hết giờ; ánh xạ sang mã chuẩn 8.6
  • So Pydantic AI và LangGraph không bật checkpointer, đề xuất một
  • Báo cáo kết luận từng ASM, đề xuất framework, chi phí đã tiêu
  • Dùng SDK chính thức của ba provider (kiến trúc 2.4; ADR-08)
  • Framework chỉ dùng bên trong một Agent Run, không bật checkpointer; ứng viên Pydantic AI, LangGraph (kiến trúc 2.4)
  • Base URL tùy chỉnh kiểm với endpoint chính thức và một endpoint tùy chỉnh mỗi provider (ASM-03)
  • Key không được vào repo, log hay báo cáo (NFR-OBS-002; AGENT.md)
  • PO cấp key khi Dev cần (H2)
