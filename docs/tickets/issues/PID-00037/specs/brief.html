Bản tóm tắt theo spec-read-skill (references/brief-template.md), đã gộp câu trả lời ở mục Làm rõ của trang ticket. Mỗi dòng dẫn nguồn: mã, đường dẫn#anchor, hoặc H1…

Làm gì

Researcher (đã đăng nhập qua eTroy OIDC; cục bộ và staging PH-02 dùng OIDC mock của PID-00160) quản lý danh sách Research Project ở Global Workspace: tạo, sửa thông tin, lưu trữ, mở lại, xóa mềm và khôi phục trong 30 ngày. Dashboard là điểm vào sau đăng nhập: khung năm khối theo thứ tự ưu tiên, khối project gần đây, trạng thái lần đầu (chưa có project, chưa có API key) và banner khôi phục khi có workflow bị gián đoạn. Lần này dựng giao diện chạy trên mock (D-UI), hội tụ với backend ở cổng PH-02.

Quy tắc

  • Global Workspace không có “project đang hoạt động”; dữ liệu project chỉ ở dạng tóm tắt, thao tác chi tiết ở Project Workspace — PRD 4.1
  • Dashboard tải khối theo thứ tự: Pending actions, Workflow đang chạy hoặc Interrupted, Project gần đây, tiến độ Task, trạng thái bản thảo, lỗi gần đây; khối lỗi không làm hỏng khối khác; chỉ project Active ở khối project; Dashboard chỉ đọc — WS-DASHBOARD-001; UX-LAYOUT-004; H2
  • Phân chia: PID này làm khung, khối Project gần đây, first-run, banner khôi phục; PID-00060 lấp các khối còn lại — H2
  • First-run: (a) không có project Active → trống có nút “Tạo project”; (b) chưa có Provider Connection → banner “Thêm API key của bạn để agent hoạt động” — WS-DASHBOARD-001-AC03; UX-SETTINGS-002-AC02; H3
  • Banner khôi phục khi có workflow Interrupted, mở Recovery decision trong đúng ngữ cảnh — UX-STATE-005; H4
  • Tạo project: tên và câu hỏi nghiên cứu bắt buộc; không tạo Manuscript ở bước này; thao tác nguyên tử; lỗi lưu giữ dữ liệu form; cảnh báo tên trùng không chặn; xong mở Project AI Chat — PROJ-CRUD-001; H5
  • Sửa: tên, mô tả ngắn, ngôn ngữ phản hồi của agent; Archived chỉ đọc; xung đột phiên bản 412 — PROJ-CRUD-002; DATA-CONC-001; H8
  • Lưu trữ, xóa là APR-08: Researcher xác nhận, hệ quả nêu trước; bị chặn khi còn workflow Running, Waiting for User, Paused, Interrupted; xóa là xóa mềm 30 ngày; khôi phục về trạng thái trước khi xóa; agent không xóa project — PROJ-CRUD-003; PRD 3.4; H7
  • Số trên TopBar, rail do shell làm — PID-00012 H1; H1
  • Bất biến: agent đề xuất, System kiểm soát, Researcher quyết định; mọi thay đổi trạng thái project chỉ do Researcher xác nhận; cách ly theo tài khoản (mở project khác tài khoản → “không tìm thấy”, PRD 4.3).

  • Mã lỗi: active_workflow_exists, restore_window_expired, precondition_failed, validation_failed trong ErrorCode — có

  • Mã nguồn: apps/web/src/features/global/index.tsx (Placeholder, i18n rỗng), apps/web/src/main.tsx — có; shell và mock (PID-00012, PID-00013) — đang làm
