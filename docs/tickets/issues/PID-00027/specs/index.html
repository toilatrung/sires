  • Truy xuất lai: vector cộng full-text top 50, gộp bằng Reciprocal Rank Fusion (kiến trúc 7.4)
  • Mỗi embedding model một bảng; bảng mẫu vec.emb_openai_text_embedding_3_small 1536 chiều (docs/database/ddl/knowledge.sql)
  • 5.000 reference mỗi tài khoản, 2.000 Source Document (NFR-SCALE-002)
