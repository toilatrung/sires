Làm

  1. stateTransitionRows(machines): kiểm danh sách (rỗng → lỗi, EC10; trùng tên → lỗi, EC09); trả dòng (machine, fromState, toState, code hay null) sắp theo code point như spec 4.1 (không dùng localeCompare) — file: libs/ts/platform/src/state-machine/sql.ts (tạo mới).
  2. stateTransitionStatements(machines) trả hai câu DELETE và INSERT … ON CONFLICT như spec 4.1; renderStateTransitionSql(machines) ghép hai dòng chú thích cố định, câu DELETE, dòng --> statement-breakpoint, câu INSERT; xuống dòng LF, kết thúc bằng LF; nháy đơn nhân đôi (EC07) — file: sql.ts.
  3. compareStateTransitionRows(actual, machines): chỉ xét dòng có machine trong danh sách; trả missing (có trong khai báo, không có trong actual), unexpected (ngược lại), codeMismatch (cùng cặp, khác mã: dòng khai báo và mã thực tế) (EC13) — file: sql.ts.
  4. Tạo bộ mẫu dùng chung: libs/ts/platform/src/state-machine/testdata/golden-machines.json (tạo mới; mảng khai báo dạng dữ liệu, khóa machine, states, transitions với from, to, code, actors) theo yêu cầu của spec 4.1: ít nhất hai machine, cặp có mã và không mã, trạng thái có khoảng trắng, một giá trị có nháy đơn, một giá trị không phải ASCII (EC08). Sinh SQL, đọc duyệt bằng mắt, lưu đúng chuỗi đó vào testdata/golden.txt (tạo mới; LF).
  5. Viết sql.spec.ts: “xác định khi đổi thứ tự” (sinh lại sau khi đảo thứ tự machine, states, transitions: giống hệt), “khớp golden.txt” (đọc file, bỏ \r — EC15), “so dòng” (thiếu, thừa, khác mã, khớp, dòng của machine khác bị bỏ qua), “danh sách machine sai” (rỗng, trùng tên) — file: libs/ts/platform/src/state-machine/sql.spec.ts (tạo mới).
