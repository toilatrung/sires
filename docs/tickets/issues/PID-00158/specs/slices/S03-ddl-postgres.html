Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

Phụ thuộcS02; Docker (Linux hoặc WSL2 với DOCKER_HOST)

Làm

  1. Thêm vào libs/ts/platform/package.json (có sẵn): devDependency @sires/testing (workspace:*), pg, @types/pg (catalog:); trong phần nx, input của target test gồm default và {workspaceRoot}/docs/database/ddl/*.sql để test chạy lại khi DDL đổi. Chạy pnpm install (lock file đổi theo, không sửa tay).
  2. Viết bộ đọc khối INSERT chỉ dùng cho test (trong libs/ts/platform/src/state-machine/testdata/ hay trong file spec; tạo mới): tìm câu INSERT INTO app.state_transition (…) VALUES …; trong một file DDL, trả câu đó và danh sách dòng (3 hay 4 cột, NULL cho mã không có). Dạng không đọc được → lỗi nêu tên file (EC20). Thêm loại trừ src/**/testdata/** vào tsconfig.build.json nếu đặt mã TS ở đó.
  3. Viết libs/ts/platform/src/state-machine/ddl.pg.spec.ts (tạo mới) với startPostgres({ extensions: [] }) và pg: chạy docs/database/ddl/00-common.sql một lần (đường dẫn tính từ gốc repo). Với từng file trong 8 file DDL ở spec 2.3: chạy câu INSERT của DDL, đọc dòng, DELETE FROM app.state_transition; dựng khai báo bằng defineStateMachine từ dòng đọc được (trạng thái = mọi giá trị xuất hiện trong cặp), chạy renderStateTransitionSql, đọc dòng, so; chạy lại SQL, so lần nữa. Ghi số đếm 8 file, 25 machine, 133 cặp và so ở cuối (EC20).
  4. Thêm ca “đồng bộ một machine”: nạp dòng của machine A lệch khai báo (bỏ một cặp, thêm một cặp lạ, đổi mã một cặp) và dòng của machine B; chạy SQL sinh cho riêng A; kiểm A bằng khai báo, B giữ nguyên (EC11, EC13); compareStateTransitionRows trên dòng trước và sau cho đúng kết quả.
  5. Dừng container sau test. Không có Docker → lỗi DockerUnavailableError của @sires/testing, không bỏ qua (EC16).

Kiểm

  • pnpm nx run @sires/platform:test → đạt (cần Docker)
  • Test: ddl.pg.spec.ts › khớp mọi khối INSERT của docs/database/ddl (PID-00158-AC04; EC20), › chạy lần hai không đổi (PID-00158-AC04; EC12)
  • Test: ddl.pg.spec.ts › đồng bộ một machine (PID-00158-AC05; EC11, EC13)
  • Thao tác tay (EC16): tắt Docker, chạy lại lệnh test, thấy lỗi rõ ở file ddl.pg.spec.ts, các file test khác vẫn đạt.

Xong khi

  • Cả 8 file DDL: dòng sinh từ helper bằng dòng của DDL, kể cả code; chạy lại không đổi; đồng bộ chỉ chạm machine truyền vào; test chạy trong nx affected của CI.
