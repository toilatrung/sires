Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

Output specO1, O7 (define.spec.ts, check.spec.ts)
Bước specB1
Edge caseEC01–EC07, EC14 (từ specs/scope.html)
Phụ thuộc— (không cần database, không cần PID khác)

Làm

  1. Tạo thư mục libs/ts/platform/src/state-machine/ (tạo mới). Viết kiểu khai báo theo spec 4.2: machine, states (danh sách, dùng as const để suy ra union trạng thái), transitions gồm from, to, code (tùy chọn), actors (tùy chọn, trong researcher, agent, system) — file: define.ts (tạo mới).
  2. defineStateMachine(decl): kiểm mọi ca ở spec 4.7 (EC02–EC07), ném StateMachineDefinitionError nêu machine và giá trị sai; trả đối tượng đóng băng sâu, kiểu readonly (EC14); giữ chỉ mục tra cặp theo (từ, đến) để tra nhanh — file: define.ts, errors.ts (tạo mới).
  3. findTransition(m, from, to) trả cặp (kèm code, actors) hay undefined; assertTransition(m, from, to) trả cặp hoặc ném InvalidTransitionError với code = 'invalid_transition', machine, currentState, targetState (EC01). Không gọi database, mạng, hay lớp HTTP — file: check.ts, errors.ts (tạo mới).
  4. Viết define.spec.ts: “nhận khai báo hợp lệ” (một machine mẫu nhỏ có mã, không mã, actor), “từ chối khai báo sai” (mỗi ca của 4.7 một trường hợp có tên), “không sửa được” (gán thuộc tính, đẩy phần tử đều không đổi được đối tượng) — file: libs/ts/platform/src/state-machine/define.spec.ts (tạo mới).
  5. Viết check.spec.ts › “mọi cặp có thứ tự”: với một machine mẫu (ví dụ 4 trạng thái, 5 cặp, có mã), duyệt mọi cặp có thứ tự kể cả X → X, so với bảng mong đợi viết tay trong test; kiểm thuộc tính của lỗi — file: libs/ts/platform/src/state-machine/check.spec.ts (tạo mới).

Kiểm

  • pnpm nx run @sires/platform:test → đạt; pnpm nx run @sires/platform:typecheck, :lint → đạt
  • Test: check.spec.ts › mọi cặp có thứ tự (PID-00158-AC01; EC01)
  • Test: define.spec.ts › từ chối khai báo sai (PID-00158-AC02; EC02–EC07), › không sửa được (EC14)

Xong khi

  • Mọi cặp khai báo được nhận kèm mã; mọi cặp khác ném InvalidTransitionError có đủ bốn thuộc tính; mọi ca khai báo sai ném StateMachineDefinitionError; test chạy không cần Docker và mạng.
