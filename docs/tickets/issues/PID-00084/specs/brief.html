Bản tóm tắt theo spec-read-skill, đã gộp câu trả lời ở mục Làm rõ của trang ticket (H1–H12, chốt theo đề xuất, PO ủy quyền 26/11/2026). Mỗi dòng dẫn nguồn.

Làm gì

Tác nhân là Researcher. Khi Orchestrator đề xuất mở phiên thảo luận, Project AI Chat hiện thẻ đề xuất (prompt purpose = deliberation_proposal) nêu vấn đề, lý do, các bên và lưu ý chi phí, với hai thao tác “Thảo luận” và “Bỏ qua”. Bỏ qua thì kết quả mang nhãn “không qua thảo luận”. Thẻ thay cho thẻ chuẩn mà PID-00058 dùng tạm cho loại prompt này. Lượt này dựng trong apps/web/src/features/project/deliberation-card/ trên mock của PID-00013 (“Xây với mock”); nối backend thật ở cổng PH-04 (H1).

Quy tắc

  • Thẻ nêu vấn đề, các bên tham gia, lưu ý chi phí; hai thao tác “Thảo luận”, “Bỏ qua” — UX-MONITOR-007; ORCH-DELIB-001; H3, H4
  • Bỏ qua: không có Agent Run của Analysis Agent, kết quả mang nhãn “không qua thảo luận” (backend); giao diện gửi đúng một câu trả lời skip — UX-MONITOR-007-AC01; ticket AC01; H6
  • Chi phí là ước lượng số Agent Run, tính trên API key của Researcher; không ước lượng tiền — DeliberationProposal.estimatedAgentRuns, costNote; OQ-099; H3
  • Cảnh báo khi Analysis Agent A, B cùng model — ORCH-DELIB-005; DEC-47; H3
  • Không chọn sẵn; trả lời một lần; Expired, Cancelled chỉ đọc, “Không được tính là đồng ý” — UX-PROMPT-002, UX-PROMPT-004; PROMPT-LIFECYCLE-001; H4, H5
  • Không chiếm operation mà PID-00058 (hội thoại) và PID-00060 (prompt) đã giữ mock — ghi chú của phiên điều phối; H7
  • Bất biến: Researcher quyết định mở phiên; giao diện không tự chọn.

Input đã kiểm

  • docs/ui-design/source/Chat.dc.html (khối “Đề xuất thảo luận”), Chat--deliberation-skipped — có
  • components/schemas/orchestration.yaml (PromptPurpose, DeliberationProposal, PromptResponse) — có; choices của prompt là deliberate, skip
  • Luồng tin nhắn và thẻ prompt trong Chat của PID-00058 (cùng khu vực project) — chưa có; làm ở PID-00058 S03, S05
  • Shell (PID-00012), mock (PID-00013) — chưa có trên main ngày 27/11/2026

Output phải tạo

  • O1 thẻ đề xuất thảo luận trong apps/web/src/features/project/deliberation-card/, i18n vi/en, đang tải, lỗi → S01, S02
  • O2 fixture prompt deliberation_proposal có type trong apps/web/src/features/project/__mocks__/ (không khai operation) → S01
  • O3 card.spec.tsx → S01, S02 (đổi tên, H8)

Thuật ngữ

  • deliberation_proposal = prompt đề xuất mở phiên thảo luận; deliberate = Thảo luận; skip = Bỏ qua
  • DeliberationLabel skipped = nhãn “không qua thảo luận”
  • Xây với mock = dựng và test với mock sinh từ OpenAPI (D-UI); Hội tụ = chạy cùng backend thật trên staging
