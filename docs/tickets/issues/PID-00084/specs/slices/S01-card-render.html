  3. Nội dung theo Chat.dc.html (EC01): đầu thẻ “Đề xuất thảo luận · loại vấn đề”, Orchestrator, giờ, bước của workflow; vấn đề; “Vì sao thảo luận” (reason); “Các bên” (Orchestrator, Analysis Agent A, B kèm perspective); “Chi phí” (khoảng estimatedAgentRuns Agent Run tính trên API key của bạn, tên kết nối từ listProviderConnections theo providerConnectionId, tối đa maxRounds vòng sau Vòng 1, costNote) (EC03); sameModelWarning → dòng cảnh báo kèm “Đổi trong Agent Models” (EC02); hai nút theo choices (nhãn và hệ quả của server, EC09) và câu giải thích Bỏ qua.
  4. Trạng thái: Open (viền brand, hai nút, không nút nào chọn sẵn, dùng được bằng bàn phím, EC11); Answered (chỉ đọc, “Bạn đã chọn …”, người, giờ); Expired, Cancelled (viền đứt, statusReason, “Không được tính là đồng ý”) (EC08). Nhãn theo namespace project; nội dung dạng chữ; một cột ở khổ hẹp (EC12).
