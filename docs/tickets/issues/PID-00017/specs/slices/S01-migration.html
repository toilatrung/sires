Làm

  1. Theo H1: thêm drizzle-kit (dev) và drizzle-orm vào apps/workspace/package.json bằng catalog:; cấu hình drizzle-kit (tạo mới, ví dụ apps/workspace/drizzle.config.ts, dialect PostgreSQL, thư mục ra migrations/); tạo migration đầu rỗng bằng drizzle-kit generate --custom trong apps/workspace/migrations/ (có sẵn thư mục, xoá .gitkeep; giữ journal của drizzle-kit), rồi chép vào đó docs/database/ddl/00-common.sql rồi docs/database/ddl/workspace.sql, bỏ câu INSERT INTO app.state_transition (S03 nạp). Không đổi schema; không tạo vai trò; không viết schema TypeScript của Drizzle cho bảng; giữ license ở đầu file SQL (node scripts/docs/add-license.mjs).
  2. Viết hàm chạy migration dùng chung (tạo mới, ví dụ apps/workspace/src/db/migrate.ts) bằng migrate() của drizzle-orm (node-postgres): nhận chuỗi kết nối của người chạy migration, áp mọi migration chưa chạy trong giao dịch, trả lỗi rõ khi thất bại (EC02).
  3. Viết fixture test (tạo mới, thư mục test của luồng): startPostgres({ extensions: [] }) của @sires/testing (EC03); tạo bốn vai trò sires_workspace_owner, _app, _system (BYPASSRLS), _purge (BYPASSRLS) như database 3.2; tạo hai database trong cùng container: một chạy migration, một chạy hai file DDL.
  4. Viết apps/workspace/src/db/migration.spec.ts (tạo mới): so schema hai database bằng cách không cần công cụ ngoài luồng (ví dụ pg_dump --schema-only chạy trong container rồi chuẩn hóa, hoặc truy vấn catalog), loại sổ migration của drizzle-orm (EC04); chạy migration lần hai không đổi (EC01); database thiếu vai trò thì migration dừng, không để schema dở (EC02). Cách so ghi ở implement.md.
  5. Khai báo {workspaceRoot}/docs/database/ddl/00-common.sql và workspace.sql là input của target test trong phần nx của apps/workspace/package.json (EC05).

Kiểm

  • pnpm nx run @sires/workspace:test → đạt
  • Test: apps/workspace/src/db/migration.spec.ts › schema khớp DDL tham chiếu (PID-00017-AC01; EC03, EC04)
  • Test: › chạy lần hai không đổi (EC01); › thiếu vai trò thì dừng (EC02)
  • Thao tác tay (EC05): sửa tạm một dòng trong workspace.sql, chạy lại lệnh test, thấy test chạy lại (không cache) và đỏ; hoàn tác.
