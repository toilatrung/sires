5. Các bước thực hiện

  1. B1 Proposal dạng diff theo file — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/manuscript:test
  2. B2 Chấp nhận, từ chối nguyên khối — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/manuscript:test
  3. B3 Outdated khi revision đổi — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/manuscript:test
  4. B4 Chèn diagram đã Accepted — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/manuscript:test
  5. B5 Phát manuscript.object_status_changed — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/manuscript:test
  6. B6 Controller và service theo hợp đồng cho 6 operation ở mục 4.2 — Kết quả: Khớp OpenAPI — Kiểm tra: Contract test
  7. B7 Ghi sự kiện qua outbox trong cùng giao dịch — Kết quả: Không có trạng thái mà thiếu sự kiện — Kiểm tra: Test rollback
  8. B8 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
  9. B9 Gọi luồng khác bằng client sinh từ hợp đồng; stub nằm trong thư mục test của luồng này — Kết quả: Không import mã service khác — Kiểm tra: Lint @nx/enforce-module-boundaries
  10. B10 Test tích hợp với Testcontainers — Kết quả: Tiêu chí nghiệm thu đạt — Kiểm tra: pnpm nx run @sires/manuscript:test
