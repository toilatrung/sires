Làm

  1. Viết src/log.ts (tạo mới): ghi một dòng JSON ra stdout cho mỗi sự kiện ở spec 4.3 với ts, event, client_id, sub khi có, mã lỗi khi có; không ghi token, code, mật khẩu, secret, cookie, header Authorization. Hàm ghi nhận được bộ ghi thay thế để test thu log.
  2. Thêm test test/flow.spec.ts › log không chứa token, mật khẩu, secret: thu log trong lúc chạy luồng của AC02, AC04, AC05, AC06; tìm mọi giá trị token, code, sires-local-gateway-secret, sires-local đã dùng.
  3. Tạo infra/local/oidc-mock/Dockerfile (tạo mới) theo mẫu infra/docker/node/Dockerfile: build từ gốc repo, pnpm install --frozen-lockfile, pnpm nx run @sires/oidc-mock:build, pnpm --filter @sires/oidc-mock deploy --legacy --prod /out; image chạy chép /out và thư mục config/, USER node, EXPOSE 9400, CMD ["node", "dist/main.js"]; không đặt NODE_ENV=production. Tạo Dockerfile.dockerignore (tạo mới): như file mẫu, thêm .sires, **/.sires.
  4. Thêm service oidc-mock vào infra/local/compose.yaml (có sẵn) theo O11: build.context: ../.., build.dockerfile: infra/local/oidc-mock/Dockerfile, image: sires/oidc-mock:local, environment OIDC_MOCK_ENV: local, OIDC_MOCK_ISSUER: http://localhost:9400, ports: ["9400:9400"], healthcheck chạy node -e gọi http://127.0.0.1:9400/health; sửa dòng chú thích đầu file (thêm OIDC mock, PID-00160).

Kiểm

  • Test: test/flow.spec.ts › log không chứa token, mật khẩu, secret (PID-00160-AC10)
  • Thao tác tay (PID-00160-AC09): pnpm local:up --build → mã 0; docker compose -f infra/local/compose.yaml ps (trong WSL ở Windows) thấy oidc-mock healthy; từ máy, curl -s http://localhost:9400/.well-known/openid-configuration có "issuer":"http://localhost:9400"; docker run --rm --entrypoint id sires/oidc-mock:local in uid của node
  • Thao tác tay (EC16): docker run --rm --entrypoint sh sires/oidc-mock:local -c "ls -a /app; find / -name provider-keys.env 2>/dev/null" không có .sires, .env, .git
  • Thao tác tay (EC13): ghi kid ở /jwks, docker compose -f infra/local/compose.yaml restart oidc-mock, kid khác
  • Thao tác tay (EC17): time docker compose -f infra/local/compose.yaml stop oidc-mock dưới 10 giây
  • pnpm nx affected -t lint typecheck test build; node scripts/docs/add-license.mjs --check, node scripts/development/check-tracks.mjs → sạch, chỉ luồng infra

Xong khi
