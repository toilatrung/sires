Làm

  1. Tạo infra/local/oidc-mock/package.json (tạo mới) theo O1: @sires/oidc-mock, type: module, script build (tsc -p tsconfig.build.json), typecheck, lint (eslint .), test (vitest run), start (node dist/main.js); oidc-provider ghim một phiên bản 9.x chính xác; dev openid-client, vitest, typescript, @types/node bằng catalog:; nx.tags type:app, lang:ts, scope:infra. Tạo tsconfig.json, tsconfig.build.json (tạo mới) theo mẫu của libs/ts/testing.
  2. Thêm infra/local/oidc-mock vào packages của pnpm-workspace.yaml (có sẵn); chạy pnpm install để sinh lại pnpm-lock.yaml (không sửa tay).
  3. Viết src/config.ts (tạo mới): đọc sáu biến của spec 4.2, trả cấu hình đã kiểm hoặc ném lỗi có thông điệp một dòng theo thứ tự kiểm ở spec 4.4; đường dẫn file mặc định tính từ thư mục package (không theo thư mục chạy lệnh).
  4. Viết src/seed.ts (tạo mới): đọc file client (mảng metadata) và file tài khoản; kiểm theo spec 4.1; hàm tra tài khoản theo sub và theo email (không phân biệt hoa thường); hàm so mật khẩu bằng timingSafeEqual trên SHA-256. Thông báo lỗi không in mật khẩu, secret.
  5. Tạo bốn file trong config/ (tạo mới) đúng nội dung của spec 4.1: clients.local.json, accounts.local.json, clients.staging.example.json, accounts.staging.example.json.
  6. Viết test/config.spec.ts (tạo mới) với các test ở mục Kiểm. Ca “không nghe cổng nào” kiểm bằng cách gọi hàm khởi động và xác nhận hàm ném lỗi trước khi tạo máy chủ.
