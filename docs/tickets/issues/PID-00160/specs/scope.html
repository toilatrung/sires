Edge case

Đã quét: cấu hình và file sai, môi trường (local, staging, production), giao thức (PKCE, redirect_uri, nonce, code dùng lại, refresh đồng thời, đăng xuất có và không có id_token_hint), proxy, khởi động lại, build image, log. Không áp dụng: database, sự kiện, phê duyệt, provider, giao diện của SIRes.
