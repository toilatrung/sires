4.4. Quy tắc và trạng thái

  • Rà Dockerfile Node, Python: build được mọi service, chạy non-root, không có dependency dev
  • Chart: tài nguyên, securityContext, ServiceAccount, biến môi trường từ Secret, chiến lược rolling update
  • Job migration theo service, lệnh lấy từ values, tắt được với service không có database
  • Script kiểm render chart với mọi apps/<service>/deploy/values.yaml
  • Mỗi service ≥ 2 bản sao, rolling update (kiến trúc 11.2, 11.3)
  • Migration của service chạy trước khi đổi mã, tương thích ngược (kiến trúc 6.10, 11.3)
  • Không dùng key tĩnh cho dịch vụ nhà cloud: quyền theo workload identity (kiến trúc 3.1, 10.3)
  • Giá trị riêng ở apps/<service>/deploy/values.yaml, luồng service giữ (quy tắc 1.4.8)

  1. B1 Rà Dockerfile Node, Python: build được mọi service, chạy non-root, không có dependency dev — Kết quả: Phần này hoạt động và có test hoặc lệnh kiểm — Kiểm tra: pnpm nx affected -t lint typecheck test build
  2. B2 Chart: tài nguyên, securityContext, ServiceAccount, biến môi trường từ Secret, chiến lược rolling update — Kết quả: Phần này hoạt động và có test hoặc lệnh kiểm — Kiểm tra: pnpm nx affected -t lint typecheck test build
  3. B3 Job migration theo service, lệnh lấy từ values, tắt được với service không có database — Kết quả: Phần này hoạt động và có test hoặc lệnh kiểm — Kiểm tra: pnpm nx affected -t lint typecheck test build
