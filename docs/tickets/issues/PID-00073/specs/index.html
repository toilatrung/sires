4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Không có API mới.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

4.4. Quy tắc và trạng thái

  • Worker nghe agent.run, vòng đời start, heartbeat, result, failure
  • Orchestrator trả lời chat, nhận diện ý định
  • Phát chat.delta

4.5. Giao diện

Không có giao diện.

4.6. Agent và model

Gọi model qua Model Gateway; prompt theo registry. Thay đổi prompt, định nghĩa agent thuộc NFR-EVAL-004. Agent không thực hiện được APR.

5. Các bước thực hiện

  1. B1 Worker nghe agent.run, vòng đời start, heartbeat, result, failure — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  2. B2 Orchestrator trả lời chat, nhận diện ý định — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  3. B3 Phát chat.delta — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  4. B4 Ghi sự kiện qua outbox trong cùng giao dịch — Kết quả: Không có trạng thái mà thiếu sự kiện — Kiểm tra: Test rollback
  5. B5 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
  6. B6 Gọi luồng khác bằng client sinh từ hợp đồng; stub nằm trong thư mục test của luồng này — Kết quả: Không import mã service khác — Kiểm tra: Lint @nx/enforce-module-boundaries
  7. B7 Test tích hợp với Testcontainers — Kết quả: Tiêu chí nghiệm thu đạt — Kiểm tra: pnpm nx run agent-core:test
