Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

Phụ thuộc—

Làm

  1. Dựng khung module của research trong apps/research/src/ và gắn vào apps/research/src/app.module.ts (có sẵn). Chia module là quyết định kỹ thuật của Dev (tickets 1.6 không liệt kê research); gợi ý theo đường dẫn Module của PID sau: evidence/ (PID-00052), claims/ (PID-00078), verification/ (PID-00094), artifacts/ (PID-00106), diagrams/ (PID-00107), kpi/ (PID-00145). Ghi cách chia ở implement.md.
  2. Cập nhật apps/research/src/app.module.spec.ts (có sẵn): service vẫn khởi động, /health trả { service: 'research', status: 'ok' }, các module khung được nạp.
  3. Sửa apps/research/README.md (có sẵn): dòng “Bản sao chỉ đọc” liệt kê replica.project_state (từ project.lifecycle_changed, chặn ghi khi project Archived hoặc đã xóa mềm), replica.reference_state (từ reference.status_changed, reference.deleted; Evidence chỉ từ Reference Trusted), replica.project_reference_scope (từ project_reference.changed; Evidence chỉ từ Reference được chọn Active) — database 3.4; thêm mục chạy migration; liệt kê module.

Kiểm

  • pnpm nx run @sires/research:test → đạt
  • Test: apps/research/src/app.module.spec.ts › nạp module khung (spec B3)
  • pnpm nx run @sires/research:build, :typecheck, :lint → đạt
  • Đọc lại apps/research/README.md (spec O3)

Xong khi

  • Service khởi động với khung module, test đạt, README ghi đúng entity sở hữu, ba bảng sao chỉ đọc và sự kiện nguồn của từng bảng.
