Edge case

Quét theo nhóm: dữ liệu biên (giới hạn độ dài, mẫu mã); dữ liệu cũ, migration; phân quyền (vai trò, khác tài khoản); sự kiện trùng (cùng id); môi trường (container, image, cache CI). Giao diện, provider, agent không áp dụng.
