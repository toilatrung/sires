Làm

  1. Cấu hình (tạo mới, ví dụ apps/audit/src/config/): chuỗi kết nối cho _app (truy vấn của người dùng, PID-00045), _system (consumer, job), người chạy migration; đọc từ biến môi trường, kiểm khi khởi động; tên biến ghi README và implement.md.
  2. Module kết nối database qua helper tenancy của PID-00001, gắn vào apps/audit/src/app.module.ts (có sẵn); không viết repository nghiệp vụ.
  3. Lệnh migrate riêng của service trong image (H3; ví dụ src/migrate.ts → dist/migrate.js, script migrate) dùng hàm của S01 (migrate() của drizzle-orm, H1); đường dẫn thư mục migrations/ tính từ vị trí file build để chạy được trong image; không gọi drizzle-kit lúc chạy (EC13). Thêm migration.enabled: true, migration.command vào apps/audit/deploy/values.yaml (H3; tên khóa theo PID-00010 S02).
  4. Cập nhật apps/audit/README.md: entity sở hữu (AuditEvent; bảng kỹ thuật kpi_snapshot, audit_export), bản sao chỉ đọc: không có, hợp đồng paths/14-shared-context-and-orchestration-architecture.yaml (phần Audit) thay cho paths/14-…, bốn vai trò, biến cấu hình, cách chạy migration và test.
  5. Chạy migration trên PostgreSQL của pnpm local:up chỉ khi PID-00159 đã merge (compose tạo vai trò — H2); chưa thì ghi “chờ PID-00159” trong report.md, không tự tạo vai trò trên compose.

Kiểm

  • pnpm nx run @sires/audit:test → đạt (gồm src/app.module.spec.ts có sẵn)
  • Test: apps/audit/src/migrate.spec.ts › lệnh migrate áp lên database rỗng (EC13)
  • pnpm nx run @sires/audit:build → có dist/migrate.js
  • Đọc lại README theo bước 4
