Bản tóm tắt theo spec-read-skill, lập ngày 17/11/2026 trong lô PH-01; cập nhật 18/11/2026 gộp câu trả lời H1–H5 (PO chấp nhận mọi đề xuất, trang ticket mục 5). Không còn điểm chưa chốt; others/issues.html là biên bản. Mỗi dòng dẫn nguồn.

Làm gì

System: dựng database sires_audit bằng migration của chính service, đúng DDL tham chiếu, kèm test chứng minh schema khớp và kho Audit Event chỉ ghi thêm (không ai sửa được, chỉ vai trò purge xóa được khi xóa project hoặc tài khoản); dựng khung (cấu hình, kết nối database, lệnh migrate) để PID-00045 viết consumer và truy vấn.

Quy tắc

  • DDL tham chiếu là chuẩn; migration sinh ra cùng schema; CI so hai database — DBD-02, database 12.4
  • Migration đầu là SQL chép từ 00-common.sql rồi audit.sql, đặt làm custom migration SQL của drizzle-kit (có journal), chạy bằng migrate() của drizzle-orm trong mã service; chỉ tiến; schema TypeScript của Drizzle do PID tính năng viết — kiến trúc 2.3, kiến trúc 6.10; H1
  • PID migration gồm test hành vi DDL, lệnh migrate riêng của service và giá trị Helm migration.enabled, migration.command — H3; drizzle-kit, drizzle-orm vào pnpm catalog qua PID-00001 — H4
  • Audit Event chỉ ghi thêm: trigger audit_event_append_only chặn UPDATE, không vai trò nào có UPDATE; _app không INSERT; chỉ _purge DELETE — docs/database/ddl/audit.sql, database 9.1
  • Mọi actor không sửa, không xóa được Audit Event — CTX-AUDIT-001-AC04
  • Audit Event bị xóa cùng project hoặc tài khoản, không bị xóa riêng — NFR-RET-008
  • id của Audit Event = id dòng outbox ở service nguồn (không có giá trị mặc định); actor_type là cột sinh từ actor->>'type' — docs/database/ddl/audit.sql
  • Bốn vai trò mỗi database do hạ tầng tạo, migration không tạo; _system, _purge BYPASSRLS; managed có cho BYPASSRLS không là DBQ-01 — database 3.2, DBQ-01; cục bộ: compose tạo ở PID-00159, tới lúc đó test tự tạo — H2
  • Trạng thái và chuyển trạng thái: không có state machine trong audit.sql; PID này không dùng helper sinh app.state_transition của PID-00158.
  • Bất biến của SIRes: mọi hành động có tác động lâu dài có actor; Audit Event không chứa API key, nội dung tài liệu hay toàn văn prompt (NFR-OBS-002, do service nguồn soạn).
