4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 7 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

4.4. Quy tắc và trạng thái

  • Đúng 2 Analysis Agent, Vòng 1 ẩn lập trường, Vòng 2 phản biện chéo
  • Deliberation Board chỉ ghi thêm
  • Context Snapshot và đánh dấu lỗi thời
  • Nhãn deliberated, skipped; cộng usage của phiên

4.5. Giao diện

4.6. Agent và model
