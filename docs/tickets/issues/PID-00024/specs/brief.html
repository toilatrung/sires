Bản tóm tắt theo spec-read-skill, gộp mục Làm rõ 17/11/2026 và câu trả lời H1–H9 của PO ngày 18/11/2026 (trang ticket, mục 5). Không còn phiếu mở; phiếu I1–I4 giữ làm biên bản. Còn một việc sửa nguồn chặn S07. Mỗi dòng dẫn nguồn.

Làm gì

Luồng library dựng database sires_library bằng migration đúng DDL tham chiếu (kèm lệnh migrate và giá trị Helm), khai báo bốn state machine dạng dữ liệu để sinh bảng chuyển trạng thái, dựng khung bốn module con, và viết parser BibTeX, RIS trong importers. Parser nhận nội dung BibTeX hoặc RIS (một hay nhiều mục), trả kết quả từng mục: ReferenceMetadata đã chuẩn hóa (H1, H2) hoặc lỗi kèm lý do, để một mục hỏng không làm hỏng cả file. Parser được API nhập reference của PID-00076 (nhập tay, LIB-IMPORT-002) và nguồn khác dùng về sau; PID này không có API, không ghi Reference.

Quy tắc

  • Bảng nền tảng app.outbox, app.inbox, app.idempotency_key, app.job_lock, app.state_transition và replica.project_state nằm trong migration của service — PID-00002 N5; DDL 00-common.sql, library.sql dòng 9
  • Migration đầu là SQL chép từ library.sql cùng các đối tượng chung của 00-common.sql, đặt làm custom migration SQL của drizzle-kit (journal), chạy bằng migrate() của drizzle-orm; chỉ tiến; đổi phá vỡ theo mở rộng → di chuyển → thu hẹp; schema Drizzle bằng TypeScript do PID tính năng viết — H5 (quyết định chung D1); kiến trúc 6.10; database 12.4
  • Service có lệnh migrate riêng và giá trị Helm migration.enabled, migration.command trong apps/library/deploy/values.yaml; image production không có drizzle-kit, Job migration chạy mã migrate trong image — H6 (D3); PID-00010 EC01
  • Vai trò sires_library_owner, _app, _system, _purge do hạ tầng tạo trước (compose cục bộ: PID-00159); migration không tạo vai trò; test tự tạo vai trò trước khi chạy migration — database 3.2; header 00-common.sql; H7 (D4)
  • Bảng app.state_transition sinh tự động từ khai báo state machine, không viết tay — database 10.2, DBQ-09, DR-01 (DEC-57). PID này khai báo bốn machine của library dạng dữ liệu trong mã domain của library và sinh dòng bằng helper của PID-00158; PID tính năng dùng lại khai báo — H3 (D2)
  • Mỗi luồng service đưa test hành vi DDL vào CI cùng migration — tickets 2, PH-01; H6 (D3). Migration có AC riêng PID-00024-AC02 — H4
  • Metadata tối thiểu để tạo reference: tiêu đề, ít nhất một tác giả, năm (hoặc ghi rõ thiếu năm); thiếu thì mục đó lỗi kèm lý do, các mục khác tiếp tục — LIB-IMPORT-001; LIB-IMPORT-002 (luồng lỗi)
  • Trùng citation key trong cùng file: báo trùng, mục sau không ghi đè mục trước — spec 4.7
  • Parser BibTeX, RIS phía TypeScript; chuẩn hóa theo schema 17.6; lỗi từng entry báo riêng — kiến trúc 8.7; thư viện theo báo cáo SPK-03 (PID-00025), kiến trúc 2.3 nêu @retorquere/bibtex-parser
  • Parser trả ReferenceMetadata (17.6): source = bibtex hoặc ris; identifiers.sourceId = citation key (BibTeX) hoặc thẻ ID (RIS); identifiers.url = trường url/UR, không có thì https://doi.org/ + DOI; retrievedAt = thời điểm parse; raw = bản gốc.
