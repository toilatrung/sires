Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

ACKhông có AC riêng (spec B4, O4)
Output specO4; khung module (spec 4.4)
Bước specB4
Edge caseKhông có
Phụ thuộc—

Làm

  1. Tạo module NestJS rỗng cho apps/library/src/sources/, doi/, importers/, references/ (thư mục có sẵn, chỉ có .gitkeep; xoá .gitkeep khi có file) và gắn vào apps/library/src/app.module.ts (có sẵn). Tên class, cách chia file do Dev chọn (tickets 1.6 chỉ định tên module con).
  2. Cập nhật apps/library/src/app.module.spec.ts (có sẵn) để kiểm bốn module được nạp và /health vẫn trả { service: 'library', status: 'ok' }.
  3. Sửa apps/library/README.md (có sẵn): dòng “Bản sao chỉ đọc” ghi replica.project_state — nhận từ project.lifecycle_changed, dùng chặn ghi khi project Archived hoặc đã xóa mềm (database 3.4, DDL tg_project_writable); thêm mục chạy migration (lệnh của S01); liệt kê bốn module con.

Kiểm

  • pnpm nx run @sires/library:test → đạt
  • Test: apps/library/src/app.module.spec.ts › nạp bốn module con (spec B4)
  • pnpm nx run @sires/library:build, :typecheck, :lint → đạt
  • Đọc lại apps/library/README.md (spec O4)

Xong khi

  • Service khởi động với bốn module con, test đạt, README ghi đúng entity sở hữu và bản sao chỉ đọc.
