Làm

  1. Tạo migration đầu tiên trong apps/library/migrations/ (có sẵn, đang rỗng) là custom migration SQL của drizzle-kit (drizzle-kit tạo file SQL rỗng và mục journal; tên file theo drizzle-kit) — H5, quyết định chung D1, kiến trúc 6.10: nội dung chép từ docs/database/ddl/00-common.sql (các đối tượng chung) rồi docs/database/ddl/library.sql, trừ câu INSERT INTO app.state_transition (S02 sinh bằng helper). Giữ nguyên tên đối tượng, ràng buộc, trigger, chính sách RLS, lệnh GRANT/REVOKE; không tạo vai trò. Không viết schema Drizzle bằng TypeScript (PID tính năng viết — N9). Chỉ tiến.
  2. Viết mã chạy migration trong apps/library/src/db/ (tạo mới) bằng migrate() của drizzle-orm (node-postgres) và script migrate trong apps/library/package.json (có sẵn), chạy được trong image không có drizzle-kit (PID-00010 EC01). Gói: drizzle-orm, pg qua catalog:, drizzle-kit là devDependency qua catalog:; gói khác chưa có trong catalog thì dừng (mục 7 trang ticket).
  3. Thêm vào apps/library/deploy/values.yaml (có sẵn) khóa migration.enabled: true và migration.command = lệnh chạy mã migrate ở bước 2 trong image (H6, quyết định chung D3; Job migration của chart thuộc PID-00010 S02). Lệnh cụ thể ghi implement.md.
  4. Test tích hợp apps/library/src/db/migration.spec.ts (tạo mới) với startPostgres của @sires/testing: tạo vai trò sires_library_owner, _app, _system (BYPASSRLS), _purge (BYPASSRLS) như database 3.2 (compose cục bộ chưa tạo tới khi có PID-00159 — H7); dựng database A bằng mã migrate của bước 2, database B bằng hai file DDL (bỏ phần INSERT chuyển trạng thái); so schema A và B (bảng, cột, kiểu, mặc định, ràng buộc, index, hàm, trigger, chính sách, quyền) — công cụ so do Dev chọn (database 12.4 gợi ý migra), ghi implement.md.
  5. Viết test hành vi DDL cho EC02–EC09 trên database A, đăng nhập bằng vai trò _app hoặc _system đúng như database 11; dữ liệu mồi replica.project_state ghi bằng _system.
  6. DDL hoặc migration lỗi trên PostgreSQL 16 mà không sửa được trong migration (EC01) → dừng, ghi đề xuất DBQ vào report.md.

  • Test: apps/library/src/db/migration.spec.ts › chạy trên PostgreSQL 16 (EC01), › thiếu vai trò (EC02), › chạy lại (EC03), › RLS (EC04), › chỉ chọn Reference Trusted (EC05), › chặn ghi theo vòng đời project (EC06), › lịch sử metadata bất biến (EC07), › ràng buộc duy nhất (EC08), › row_version (EC09)
