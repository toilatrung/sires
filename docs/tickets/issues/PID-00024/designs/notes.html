Chỉ ghi điều spec mục 4 chưa nói và đã chốt khi làm rõ (H<n>). PO trả lời phiếu I1–I4 và đưa sáu quyết định chung D1–D6 ngày 18/11/2026 (H1–H9, trang ticket mục 5). Điều rút thẳng từ nguồn (DDL, database, LIB-IMPORT-001) ghi ở brief; chi tiết hiện thực Dev tự quyết (tên file migration theo drizzle-kit, công cụ so schema, cấu trúc parser, nơi đặt khai báo state machine) ghi ở implement.md.

Dữ liệu

  • Migration (H5, D1): custom migration SQL của drizzle-kit (journal) chép từ 00-common.sql (đối tượng chung) và library.sql, chạy bằng migrate() của drizzle-orm; chỉ tiến; không có schema Drizzle bằng TypeScript ở PID này. Lệnh migrate riêng của service; apps/library/deploy/values.yaml có migration.enabled: true, migration.command (H6, D3).
  • Bảng chuyển trạng thái (H3, D2): bốn machine khai báo dạng dữ liệu trong mã domain của library, đúng các cặp from → to của library.sql; dòng app.state_transition sinh bằng helper PID-00158 và nằm trong migration; PID tính năng dùng lại khai báo.
  • Điền ReferenceMetadata từ BibTeX, RIS (H1): source = bibtex | ris; identifiers.sourceId = citation key | thẻ ID; identifiers.url = url | UR, không có thì https://doi.org/ + DOI; retrievedAt = thời điểm parse; raw = bản gốc. Thiếu URL và DOI hoặc thiếu ID → bỏ trường tương ứng, hợp lệ khi PO đã nới hợp đồng (S07).
  • Chuẩn hóa giá trị (H2): ký hiệu LaTeX → Unicode thuần ở mọi trường chuẩn hóa ({\"o} → ö, \& → &, bỏ ngoặc giữ chữ hoa; công thức toán giữ nguyên chuỗi); authors[].name = “Họ, Tên” (BibTeX “Tên Họ” đổi sang “Họ, Tên”; tên tập thể trong ngoặc giữ nguyên).
