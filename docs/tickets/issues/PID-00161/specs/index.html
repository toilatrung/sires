4.2. API

Không có API mới.

4.3. Sự kiện

4.4. Quy tắc và trạng thái

  • Lịch hằng ngày (database 12.2).

  • Không được sửa: thư mục ngoài luồng gateway; docs/; file sinh tự động; migration đã có.
