Thiết kế đã duyệt nằm ở design.md và các màn dưới đây (DEC-18). File này ghi màn, trạng thái cần dựng và điều đã chốt khi làm rõ ngày 27/11/2026 mà spec mục 4 chưa nói (H1… ở trang ticket mục 5). Trạng thái thiết kế chưa vẽ có ở sketch Manuscript-states.html. Chi tiết hiện thực Dev tự quyết ghi ở implement.md.

Dữ liệu

Không có bảng. Fixture của mock (S01) khớp Manuscript.html và dùng chung một project mẫu: bản thảo Default (pdfLaTeX, natbib), file main.tex, bibliography/references.bib, sections/intro.tex, sections/method.tex (được \input ở main.tex dòng 12), figures/; revision r15 (System, Khởi tạo Default), r16 (Researcher, Sửa trực tiếp · main.tex), r17 (Writing Agent, Proposal đã chấp nhận · T-2.1), r18 (Researcher, Sửa trực tiếp · method.tex) là hiện hành; một proposal Proposed trên sections/intro.tex (T-2.1, 2 claim, 3 evidence, 2 file, citation 2/2 phân giải), một proposal có citation lỗi asai2024selfrg, một proposal Outdated gốc r16; build r16 Succeeded, r17 Failed (thiếu package booktabs ở main.tex dòng 4, citation gao2023survy không phân giải ở sections/intro.tex dòng 7); bibliography có lewis2020rag, gao2023survey, một entry của reference Revoked; reference của project có smith2020 chưa có entry. Có kịch bản chưa khởi tạo, Archived, xung đột khi lưu, build đang chạy. PDF mẫu tự tạo, không chứa nội dung có bản quyền. Dữ liệu mẫu theo design.md §6 (tổng khớp, cùng Task cùng mã ở mọi nơi).

API và sự kiện

  • 26 operation ở spec mục 2.3; khu vực khai override 20 operation path 12 (H3); gọi qua client API có type của shell; Idempotency-Key cho initManuscript, commitManuscriptChanges, acceptChangeProposal, rejectChangeProposal, sendMessage.
  • Sự kiện qua client SSE của shell: manuscript.object_status_changed theo objectType (change_proposal → proposal; build → build, chip, PDF, log; revision → manuscript, cây file). Nhận sự kiện thì tải lại bằng GET; không dựng trạng thái từ payload; không polling. Shell báo đã nối lại hoặc cần tải lại (replay.unavailable, PC-05 P2) → tải lại dữ liệu của khu vực (H19).
  • Liên kết đi: Task /projects/{projectId}/tasks/{taskId}; claim /projects/{projectId}/claims/{claimId}; workflow của Agent Run /projects/{projectId}/activity/workflows/{workflowId}; Project AI Chat /projects/{projectId}/chat; Overview /projects/{projectId}/overview (PRD 4.3). Liên kết đến: /projects/{projectId}/manuscript/ kèm đường dẫn file, và ?proposal={proposalId} cho pending action Manuscript change proposal (H11).
