Edge case

Quét theo nhóm áp dụng: dữ liệu rỗng và biên (chưa có bản thảo, chưa có PDF, nhiều trang revision, file nhị phân, thư mục rỗng); đường dẫn (thoát thư mục, trùng, file đang được tham chiếu); đồng thời (revision mới hơn khi lưu, proposal đã xử lý ở tab khác, bấm hai lần, idempotency); trạng thái (proposal Proposed, Outdated, Accepted, Rejected; build Queued, Running, Succeeded, Failed; project Archived); phê duyệt (APR-05 nguyên khối, citation check, thay đổi chưa lưu); sự kiện và nối lại SSE; chạy lâu (build); giao diện (đang tải, lỗi từng vùng, 1440, 1024, 390 px, vi/en, bàn phím); nội dung nguy hiểm (HTML trong diff, log, tin nhắn); cách ly (project của tài khoản khác). Nhóm migration, model không áp dụng.
