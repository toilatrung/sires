Làm

  1. Tab “Lịch sử” theo Manuscript--rightPane-history và H14: listManuscriptRevisions mới nhất trước, “Tải thêm” theo cursor (EC43); mỗi dòng: rN (mono), actor (Researcher → tên tài khoản của shell; agent → tên agent; System), giờ, nguồn (direct_edit “Sửa trực tiếp · file”, change_proposal “Proposal đã chấp nhận · Task”, có artifactVersionIds “Chèn sơ đồ” (quy ước ở mô tả ManuscriptRevision.source), init “Khởi tạo Default/Blank”), ô chọn. Sau khi lưu ở S04, revision mới hiện trên cùng.
  2. So sánh: chỉ bật khi chọn đúng hai revision, lý do cạnh nút (EC41); “So sánh rA ↔ rB” tính diff theo file ở giao diện: listManuscriptFiles(revisionId) hai bên so contentHash, file khác nhau lấy getManuscriptFileContent(revisionId) hai bên rồi diff dòng; mỗi bên ghi actor, nguồn; file nhị phân ghi “đã đổi”; file thêm hoặc xóa hiện toàn bộ (EC40).
  3. Chi tiết revision (getManuscriptRevision): file đổi; nguồn change_proposal → liên kết Task (/projects/{projectId}/tasks/{taskId}), Agent Run (workflow /projects/{projectId}/activity/workflows/{workflowId} theo provenance của proposal qua getChangeProposal), claim (/projects/{projectId}/claims/{claimId}); không có Task thì không có liên kết Task (EC43).
  4. Khôi phục (Manuscript--rightPane-compare): “Khôi phục file này về rN” trong so sánh và chi tiết, cho file văn bản và nhị phân → commitManuscriptChanges modify (hoặc add nếu file đã xóa) kèm restoreFromRevisionId = id của rN, message “Khôi phục file về rN”; revision mới actor Researcher, lịch sử giữ nguyên; file có thay đổi chưa lưu → vô hiệu kèm lý do (EC42). “Khôi phục toàn bộ về rN”: hộp xác nhận nêu số file sửa, thêm lại, xóa; một commit gồm modify/add kèm restoreFromRevisionId cho file khác rN và delete cho file không có ở rN, bỏ qua bibliography/references.bib; còn file chưa lưu → vô hiệu kèm lý do; 409 xử lý như H7 (EC57). Mọi điều khiển dùng được bằng bàn phím (EC55).
