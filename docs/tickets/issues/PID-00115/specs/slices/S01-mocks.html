Làm

  1. Đọc README mock của PID-00013 (apps/web/src/shell/mock/) và hợp đồng Feature của shell. Khai override qua hợp đồng Feature từ apps/web/src/features/manuscript/__mocks__/ (tạo mới), dùng type sinh từ OpenAPI, không viết tay kiểu dữ liệu.
  2. Override có trạng thái, chung một kho dữ liệu, cho 20 operation path 12 theo H3: getManuscript, initManuscript, listManuscriptFiles, getManuscriptFileContent, commitManuscriptChanges, listManuscriptRevisions, getManuscriptRevision, listChangeProposals, getChangeProposal, acceptChangeProposal, rejectChangeProposal, insertDiagramIntoManuscript, listBibliography, addBibliographyEntry, listBuilds, startBuild, getBuild, getBuildLog, getBuildPdf, exportManuscript.
  3. Hành vi theo hợp đồng: commit tạo revision số tiếp theo, baseRevisionId lệch trả 409 base_revision_mismatch, Change Proposal Proposed trên file bị đổi chuyển Outdated; accept kiểm base và citationCheck.passed (409 base_revision_mismatch, citation_check_failed), tạo revision nguồn change_proposal; addBibliographyEntry idempotent theo reference, tạo revision actor System sinh lại references.bib; startBuild idempotent theo revision (200 khi đã có), Queued → Running → Succeeded hoặc Failed theo hẹn giờ ngắn; exportManuscript trả header X-Build-Revision; project Archived trả 409 project_archived cho lệnh ghi.
  4. Phát manuscript.object_status_changed (objectType change_proposal, build, revision) qua mock /events của PID-00013 khi trạng thái đổi.
  5. Fixture theo designs/notes.html › Dữ liệu (khớp Manuscript.html): cây Default, revision r15–r18, proposal Proposed, proposal citation lỗi, proposal Outdated, build Succeeded r16 và Failed r17, bibliography và reference của project. PDF mẫu là file nhỏ tự tạo, không chứa nội dung có bản quyền. Có hàm cho test đặt kho về fixture, chọn kịch bản (chưa khởi tạo, Archived, build lỗi…).
  6. Không khai override cho operation của khu vực khác (listProjectReferences, getClaim, getTask, listConversations, createConversation, sendMessage, uploadFile); test của khu vực override cục bộ bằng helper của PID-00013.

Kiểm

  • pnpm nx run @sires/web:test → apps/web/src/features/manuscript/__mocks__/manuscript-mock.spec.ts › đăng ký không trùng (EC56); › commit lệch base trả 409; › accept chuyển Accepted và tạo revision; › lưu file làm proposal Outdated; › build qua các trạng thái và phát sự kiện
  • pnpm nx run @sires/web:typecheck → đạt (override dùng type sinh)
