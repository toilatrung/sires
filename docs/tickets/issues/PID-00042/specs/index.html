4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 7 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

4.4. Quy tắc và trạng thái

  • CRUD Provider Connection, key dạng che
  • Kiểm tra kết nối qua agent-core
  • Danh mục model theo capability
  • Phát provider_connection.changed

4.5. Giao diện

Không có giao diện.

4.6. Agent và model

Không gọi model trực tiếp.
