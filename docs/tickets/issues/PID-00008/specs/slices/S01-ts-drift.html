Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

Output specO1

Phụ thuộcPID-00007 S01 (type AsyncAPI) đã merge để kiểm cả message; phần OpenAPI làm được trên bộ sinh hiện có. PID-00007 chưa làm: ghi nhận, không chặn (H4). EC02 theo H3.

Làm

  1. Viết libs/ts/contracts/scripts/check-drift.mjs (tạo mới): gọi bộ sinh scripts/generate.mjs (có sẵn) để sinh lại type, lấy danh sách project TypeScript phụ thuộc @sires/contracts từ đồ thị Nx, chạy tsc --noEmit theo tsconfig.json của từng project; nhận thêm đường dẫn để kiểm fixture.
  2. Lỗi có kiểu nằm trong src/generated (trường thừa trong object literal, đọc trường không có) in thành một dòng: file:dòng, tên trường, schema hoặc message. Lỗi khác in nguyên văn, không gắn nhãn trường (EC02, H3). Có lỗi bất kỳ thì thoát mã khác 0; in danh sách project đã kiểm (EC05).
  3. Thêm script và target check-drift, test vào libs/ts/contracts/package.json (có sẵn); thêm vitest (catalog:, đã có trong catalog) vào devDependencies nếu dùng Vitest.
  4. Fixture trong libs/ts/contracts/scripts/__fixtures__/ (tạo mới): một file dùng type sinh đúng, một file ghi trường không có trong schema, một file có lỗi kiểu không liên quan hợp đồng, một bản spec lỗi cú pháp cho EC03 (đặt trong fixture, không sửa docs/).
  5. Viết libs/ts/contracts/scripts/check-drift.spec.mjs (tạo mới); ghi ở implement.md cách nhận diện lỗi thuộc type sinh.

Kiểm

  • pnpm nx run @sires/contracts:check-drift → đạt trên repo hiện tại, in danh sách project đã kiểm
  • pnpm nx run @sires/contracts:test → đạt
  • pnpm nx run @sires/contracts:typecheck, pnpm nx run @sires/contracts:lint → đạt
  • Test: libs/ts/contracts/scripts/check-drift.spec.mjs › trường không có trong spec (PID-00008-AC01)
  • Test: libs/ts/contracts/scripts/check-drift.spec.mjs › lỗi không thuộc hợp đồng (EC02)
  • Test: libs/ts/contracts/scripts/check-drift.spec.mjs › spec lỗi cú pháp (EC03)
  • Test: libs/ts/contracts/scripts/check-drift.spec.mjs › luôn sinh lại (EC04)
  • Thao tác tay: chạy lệnh trên repo hiện tại, đối chiếu danh sách project đã kiểm (EC05)
  • node scripts/development/check-tracks.mjs → chỉ luồng contracts

Xong khi

  • Thêm một trường không có trong spec vào fixture thì lệnh thoát lỗi và nêu đúng trường, file:dòng; bỏ trường đó thì lệnh đạt.
  • Sau khi PID-00007 S01 merge, fixture dùng type message AsyncAPI cũng bị bắt như trên.
