Làm

  1. Mở rộng libs/ts/contracts/scripts/check-drift.mjs: sau khi sinh client và mô hình Python (bộ sinh của PID-00007), chạy mypy cho project Python dùng chúng — agent-core, knowledge, sires-common — bằng target typecheck có sẵn của từng project hoặc gọi mypy trực tiếp trên fixture.
  2. Lỗi có kiểu nằm trong gói sires_common.generated in thành một dòng: file:dòng, tên trường, mô hình; lỗi khác xử lý như EC02 của S01 (thoát lỗi, in nguyên văn — H3).
  3. Thiếu uv: in rõ “thiếu uv”, không báo đạt cho phần Python, phần TS vẫn chạy (EC07).
  4. Fixture Python trong libs/ts/contracts/scripts/__fixtures__/python/ (tạo mới): một file dùng mô hình sinh đúng, một file dùng trường không có trong mô hình.
  5. Nếu mypy chỉ bắt được trường thừa khi bật plugin hay tùy chọn trong cấu hình của project Python (thuộc luồng khác) → dừng, đề xuất PID cho luồng đó (N8), không tự sửa.
