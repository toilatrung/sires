1. Ticket

  • Mục đích: ADR-14 yêu cầu CI chặn code lệch hợp đồng, và cổng PH-01 yêu cầu baseline hợp đồng đã duyệt trước khi các luồng code song song.
  • Gồm: Script so type sinh ra với mã đang dùng, chạy được trong CI; Danh sách kiểm baseline: type sinh không lỗi sau khi DBQ-03, DBQ-04 đã sửa.
  • Không gồm: Sửa docs/api-design theo DBQ-03, DBQ-04: PO thực hiện; Gắn vào pipeline CI (PID-00009).

Đầu vào

  • PID phải xong trước: PID-00007
  • Điều kiện ngoài: DBQ-03, DBQ-04

Đầu ra

  • Tệp: libs/ts/contracts/scripts/check-drift.mjs — Kiểm lệch spec

2. Tiêu chí nghiệm thu

  • PID-00008-AC01 Given service dùng trường không có trong spec, When chạy kiểm tra, Then lệnh thoát lỗi và nêu đúng trường.
  • PID-00008-AC02 Given DBQ-03, DBQ-04 đã sửa vào spec, When generate, Then không lỗi và báo cáo baseline sẵn sàng cho PO duyệt.

  • PID phải xong trước: PID-00007 Sinh type TS từ AsyncAPI và client Python từ hợp đồng.
