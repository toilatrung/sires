  2. B2 Đọc, ghi board; xác nhận entry — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  3. B3 Nghe deliberation.entry_added, deliberation.entry_finalized, deliberation.entry_retracted — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  4. B4 Orchestrator tổng hợp giữ bất đồng — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run agent-core:test
  5. B5 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
