S04 — Xóa Provider Connection và chọn kết nối thay thế

Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây. Theo H9 (chốt theo đề xuất, PO ủy quyền 26/11/2026). Dialog dựng theo design.md §4 (Dialog) và sketch designs/Settings-states.html.

ACAGENT-PROVIDER-002-AC03
Output specO1 (SettingsProviders), O3
Bước specB3, B8; H9
Edge caseEC26, EC27, EC28 (từ specs/scope.html)
Phụ thuộcS03 (bảng, cột hành động, fixture kết nối)

Làm

  1. “Xóa” ở cột hành động mở dialog (rộng 480 px, nền surface, lớp phủ theo design.md §4): tên kết nối, hệ quả, nút hủy “Giữ kết nối”, nút xác nhận “Xóa kết nối” (EC26).
  2. Kết nối có assignedAgents: dialog liệt kê agent (tên hiển thị từ listAgents; default ghi “Mặc định”) và nhóm chọn kết nối thay thế gồm các kết nối Valid khác; chưa chọn thì nút xác nhận vô hiệu; không có kết nối Valid khác → nút vô hiệu và liên kết “Thêm kết nối” (EC27).
  3. Xác nhận → deleteProviderConnection (kèm replacementConnectionId khi có); 204 → làm mới bảng và gán agent; 409 connection_in_use → tải lại danh sách, mở lại dialog với agent mới (EC28); lỗi khác theo UX-STATE-003.
  4. Dialog dùng được bằng bàn phím (focus vào dialog khi mở, Esc đóng, focus trả về nút “Xóa”).

Kiểm

  • pnpm nx run @sires/web:test → đạt
  • apps/web/src/features/settings/providers.spec.tsx › xóa (EC26); › xóa cần thay thế (AGENT-PROVIDER-002-AC03, EC27); › 409 connection_in_use (EC28)
  • Thao tác tay trên mock: xóa kết nối đang gán cho agent, chọn thay thế, xác nhận; chỉ dùng bàn phím

Xong khi

  • Không xóa được kết nối đang gán khi chưa chọn kết nối thay thế; dialog dùng được bằng bàn phím
