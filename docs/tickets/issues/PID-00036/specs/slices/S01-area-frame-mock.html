Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây. Slice nền: mọi slice sau dùng route, menu, namespace i18n và mock lập ở đây.

Làm

  1. Đọc docs/ui-design/design.md (§2–§7), năm màn tham chiếu và các trang trạng thái ở docs/ui-design/pages/ (SignIn*, Settings*), designs/notes.html, README của shell và README mock của PID-00013.
  2. apps/web/src/features/settings/index.tsx: thay placeholder bằng route thật qua hợp đồng Feature: sign-in, settings/profile, settings/providers, settings/agents, settings/preferences; thêm settings chuyển tới settings/profile (EC01). Route con lạ để shell hiện “không tìm thấy”.
  3. Khung Settings dùng chung cho bốn view: menu bên trái bốn mục (Profile, Provider Connections, Agent Models, Preferences) theo SettingsProfile, mục đang mở có aria-current="page"; một panel cho mỗi nhóm; hàng flex flex-wrap: wrap để dưới 768 px menu xếp lên trên (design.md §5, EC04).
  4. Namespace settings trong apps/web/src/features/settings/i18n/vi.json, en.json: mọi chuỗi của năm màn; nhãn English lấy từ màn tham chiếu khi có, thuật ngữ cố định giữ nguyên (design.md §6). Không còn chuỗi cứng (B7, EC03).
  5. Mock của khu vực trong apps/web/src/features/settings/__mocks__/: sinh phần mock cho 16 operation theo README của PID-00013 (updateProfile, updatePreferences, getVerificationThresholds, updateVerificationThresholds, resetVerificationThresholds, listProviderConnections, createProviderConnection, updateProviderConnection, testProviderConnection, deleteProviderConnection, listAgents, listAgentModelAssignments, setAgentModelAssignment, clearAgentModelAssignment, getEmbeddingSettings, setEmbeddingSettings); không khai getSession, getMe, startLogin (H10). Khai qua hợp đồng Feature.
  6. Override có type và fixture lấy dữ liệu mẫu của màn tham chiếu: ba kết nối (Claude cá nhân Valid, OpenAI cá nhân Valid có model embedding, Gemini cá nhân Invalid auth_failed) và một kết nối proxy Valid dùng tên miền ví dụ (https://llm-proxy.example/v1); chín agent (Analysis instances A, B); gán Mặc định và ghi đè như SettingsAgents; embedding text-embedding-3-small; ngưỡng 0,80 / 0,50 / 0,60 (isDefault = true). Không dùng key thật hay host proxy thật (D-KEY). Kho trong bộ nhớ của override giữ thay đổi trong một lần chạy dev để thao tác tay được (EC09 của PID-00013).
  7. Mỗi view dùng component đang tải, trống, lỗi của shell; lỗi tải hiện theo UX-STATE-003 kèm “Thử lại” (EC02).
  8. Test apps/web/src/features/settings/settings-nav.spec.tsx dùng tiện ích test của PID-00013.

Kiểm

  • pnpm nx run @sires/web:test, pnpm nx run @sires/web:typecheck, pnpm nx run @sires/web:lint → đạt
  • apps/web/src/features/settings/settings-nav.spec.tsx › /settings chuyển profile (EC01); › route lạ (EC01); › menu bốn mục; › đang tải, › lỗi tải (EC02); › đổi ngôn ngữ giữ form (EC03)
  • Test kiểm mock của shell (PID-00013) vẫn đạt: không trùng operation giữa khu vực settings và mock dùng chung
  • Thao tác tay: bật mock của PID-00013, mở bốn view Settings ở 1440×900, 1024×768, 390×844; không cuộn ngang (EC04)

Xong khi
