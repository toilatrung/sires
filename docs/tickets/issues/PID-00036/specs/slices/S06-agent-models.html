Làm

  1. View /settings/agents theo SettingsAgents: câu dẫn kèm liên kết “Quản lý Provider Connections”; khối Mặc định (kết nối, model, câu “Agent chọn ‘Dùng mặc định’ sẽ theo cấu hình này”); bảng Agent, Connection, Model, Trạng thái, “Sửa” cho Orchestrator và tám Specialist Agent, Analysis Agent hai dòng A, B; dòng Embedding model. Dữ liệu từ listAgents, listAgentModelAssignments, listProviderConnections, getEmbeddingSettings.
  2. Chưa có kết nối Valid → hướng dẫn kèm liên kết tới Provider Connections, không mở panel sửa (EC37). Chưa có Mặc định và agent không gán riêng → “Chưa cấu hình” kiểu cảnh báo (EC44).
  3. Panel sửa (“Đang sửa”): bước 1 chọn kết nối, chỉ kết nối Valid chọn được, kết nối khác hiện kèm chip và vô hiệu (EC38), liên kết “Thêm connection mới”; bước 2 chọn model từ availableModels, bỏ model chỉ có năng lực embedding (EC39); không có danh sách → ô nhập tay ghi “chưa xác minh” (EC24, EC40); dòng “Danh sách lấy từ connection lúc” HH:mm theo lastTestedAt, “Làm mới” gọi testProviderConnection (Invalid → lỗi theo H6, EC47). “Lưu cho agent này” → setAgentModelAssignment (Analysis kèm instance); “Dùng mặc định” → clearAgentModelAssignment (EC43); 422 model_not_available → lỗi ở ô model (EC40).
  4. capabilityWarnings hiện ở cột Trạng thái kiểu cảnh báo (EC41); sameModelWarning trên dòng Analysis → banner của thiết kế (EC42); cả hai không chặn lưu.
  5. Dòng Embedding: chỉ kết nối Valid openai, google và model có năng lực embedding (UX-SETTINGS-003-AC01, EC39); 404 → “Chưa chọn”, chọn lần đầu gọi setEmbeddingSettings ngay (EC45). Đổi model đang có → dialog SettingsAgents--state-confirm-embedding: model cũ → mới; số Reference phải index lại lấy từ trường của hợp đồng (Phải sửa ở nguồn mục 3), tới khi có thì câu “Mọi Reference đã index phải index lại toàn bộ”; usage trên kết nối; truy xuất evidence tạm không khả dụng; “Giữ model hiện tại” đóng, “Đổi và index lại” gọi setEmbeddingSettings (EC46).
  6. Không có tham số nâng cao của model (N9).
