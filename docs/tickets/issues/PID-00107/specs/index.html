4. Thiết kế kỹ thuật

4.1. Dữ liệu

4.2. API

Hiện thực đúng 6 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

5. Các bước thực hiện

  1. B1 Danh sách kiểu sơ đồ, yêu cầu tạo, kiểm nguồn, preview — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/research:test
  2. B2 Tool validateMermaidTool, renderMermaidTool — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/research:test
  3. B3 Gửi sandbox.build, nghe sandbox.reply — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/research:test
  4. B4 Controller và service theo hợp đồng cho 6 operation ở mục 4.2 — Kết quả: Khớp OpenAPI — Kiểm tra: Contract test
  5. B5 Ghi sự kiện qua outbox trong cùng giao dịch — Kết quả: Không có trạng thái mà thiếu sự kiện — Kiểm tra: Test rollback
  6. B6 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
  7. B7 Test tích hợp với Testcontainers — Kết quả: Tiêu chí nghiệm thu đạt — Kiểm tra: pnpm nx run @sires/research:test
