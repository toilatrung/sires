Làm

  1. Nút theo trạng thái theo H17: Pending Approval (Duyệt, Sửa rồi duyệt, Từ chối, Gộp khi nghi trùng — dùng lại lệnh của S07); Trusted (Sửa metadata, Thêm vào project, Thu hồi, Xóa khi usedInProjectCount bằng 0, Gộp khi nghi trùng); Revoked, Rejected (Duyệt lại, Xóa khi không dùng; metadata chỉ đọc, EC36). Một nút chính mỗi màn (design.md §4).
  2. Sửa metadata: form theo H17, đăng ký kho nháp (EC27); updateReferenceMetadata merge-patch với If-Match và metadata đầy đủ, không gửi bibtexKey; 412 → báo, đọc lại, giữ nội dung (EC35); 409 → đọc lại.
  3. Thêm vào project: dialog chọn project Active (listProjects), vô hiệu project đã có (getReferenceUsage), lý do tùy chọn → selectReferencesForProject; 422 reference_not_trusted, 409, không có project Active → theo EC37.
  4. Thu hồi: dialog 480px nêu số từ getReferenceUsage, lý do bắt buộc, “Giữ Trusted” / “Thu hồi reference” → revokeReference (Idempotency-Key) → chip Revoked và tóm tắt impact (EC38). Duyệt lại: dialog lý do tùy chọn → reinstateReference (Idempotency-Key).
  5. Gộp: dialog nêu reference đích và hệ quả → mergeReference (Idempotency-Key) → mở trang reference đích. Xóa: dialog APR-08 → deleteReference → về /library; 409 → nêu nơi dùng, gợi ý Thu hồi (EC39). Hủy mọi dialog không gọi API (EC34).
  6. Test trong apps/web/src/features/library/reference.spec.tsx (override listProjects cục bộ): thêm vào project không duyệt lại, reference chờ duyệt không thêm vào project, thu hồi nêu ảnh hưởng hai project, sửa tiêu đề giữ key, sửa xung đột phiên bản, Revoked chỉ đọc, thêm vào project các trường hợp, xóa bị từ chối khi đang dùng.
