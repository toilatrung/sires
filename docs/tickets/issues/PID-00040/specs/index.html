4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 1 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

4.4. Quy tắc và trạng thái

  • GET /events với Last-Event-ID
  • Nghe mọi message có gateway trong x-consumers
  • Lọc theo tài khoản, lưu app.sse_event_log

4.5. Giao diện

Không có giao diện.

4.6. Agent và model

Không gọi model trực tiếp.
