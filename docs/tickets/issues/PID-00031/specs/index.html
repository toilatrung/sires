4.4. Quy tắc và trạng thái

  • Dựng container thử: TeX Live cố định, latexmk, chạy bằng runsc, không mạng, non-root, read-only rootfs
  • Đo thời gian, bộ nhớ của bài báo mẫu và luận văn mẫu, cả pdfLaTeX và XeLaTeX tiếng Việt
  • Thử tấn công: lệnh shell, đọc file ngoài workspace, gọi mạng, vòng lặp vô hạn, ăn bộ nhớ
  • Báo cáo số đo, kết quả tấn công, kết luận ASM-07, đề xuất cho image thật
  • Container gVisor, không mạng, non-root, read-only rootfs; giới hạn 120 s, 2 GB, đĩa 500 MB (kiến trúc 9; ADR-11)
  • latexmk -pdf hoặc -xelatex, -interaction=nonstopmode -halt-on-error -file-line-error -no-shell-escape (kiến trúc 9)
  • Đo template Default và luận văn mẫu (ASM-07)
  • Build vượt giới hạn: Failed với timeout hoặc memory_limit (kiến trúc 9)
  • Đọc /etc/passwd qua \input phải thất bại (NFR-SANDBOX-001-AC01)
