Edge case

Đã quét: dữ liệu cũ (volume có sẵn), chạy lại, thuộc tính sai, tên đặc biệt, quyền chéo, môi trường (Windows, WSL, Docker chưa chạy), DDL chưa chạy thử trên PostgreSQL 16. Không áp dụng: giao diện, provider, sự kiện, phê duyệt.
