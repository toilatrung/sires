4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 4 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

  • Phát prompt.status_changed
