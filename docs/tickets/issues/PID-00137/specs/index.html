5. Các bước thực hiện

  1. B1 Xoay KEK không gián đoạn — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/identity:test
  2. B2 Xóa tài khoản: phát account.deletion_requested, nghe data.purged — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/identity:test
  3. B3 Ghi sự kiện qua outbox trong cùng giao dịch — Kết quả: Không có trạng thái mà thiếu sự kiện — Kiểm tra: Test rollback
  4. B4 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
  5. B5 Test tích hợp với Testcontainers — Kết quả: Tiêu chí nghiệm thu đạt — Kiểm tra: pnpm nx run @sires/identity:test
