Làm

  1. Test libs/ts/sample-service/src/ddl-pg16.spec.ts (tạo mới) dùng một container startPostgres (image pgvector/pgvector:pg16). Với mỗi service có file DDL trong docs/database/ddl/ (agent-core, audit, gateway, identity, knowledge, library, manuscript, orchestration, planning, research, workspace): tạo database riêng, tạo vai trò sires_<svc>_app, _system, _purge (database 3.2; D4), chạy 00-common.sql rồi <svc>.sql (đọc file, không sửa).
  2. Kiểm cả 11 database dựng không lỗi; ở database của knowledge kiểm extension vector có phiên bản ≥ 0.8, bảng vector mẫu có cột vector(1536) và index HNSW đã tạo (database 12.4 “Chưa kiểm”).
  3. Lỗi ở một file (EC10): thông báo của test nêu đúng service, file và câu lệnh lỗi. Dev ghi DBQ trong report.md (mục Đề xuất cho PO), không sửa docs/database/ddl/ và không bỏ qua file lỗi trong test; slice chưa xong tới khi PO sửa DDL.
  4. Ghi vào report.md phiên bản PostgreSQL, pgvector của lần chạy và kết quả từng database, để PO ghi vào database 12.4. Bộ test hành vi DDL của từng service không làm ở đây (N9, H7).
