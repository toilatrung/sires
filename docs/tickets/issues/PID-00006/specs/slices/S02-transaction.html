Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây. (Trước 18/11/2026 là S01.)

Phụ thuộcS01 (project, migration mẫu); PID-00002 S01 (outbox), S04 (audit-emit) đã merge; PID-00001 (helper tenancy, Drizzle) đã merge; PID-00004 đã merge. Hai PID đầu chưa có trên main ngày 17/11/2026: tới khi merge, slice dừng và báo (không chặn Sẵn sàng, H8).

Làm

  1. Tạo module NestJS mẫu trong libs/ts/sample-service/src/ (project của S01): schema Drizzle bằng TypeScript của bảng mẫu (phần tính năng, D1) và một lệnh đổi trạng thái.
  2. Phần dựng database trong test: PostgreSQL 16 + pgvector của startPostgres, test tạo vai trò _app, _system, _purge của service mẫu rồi chạy lệnh migrate của S01 (không dựng schema bằng SQL riêng trong test).
  3. Lệnh đổi trạng thái chạy trong một giao dịch có app.account_id (helper của PID-00001): cập nhật trạng thái, ghi sự kiện domain qua outbox (có aggregate type, id, version), gọi audit-emit (Audit Event qua outbox, audit.recorded) — chỉ dùng API của PID-00002, không tự ghi bảng outbox.
  4. Test AC01 đọc lại bằng kết nối quản trị: trạng thái mới, một dòng kind = event, một dòng kind = audit cùng giao dịch. Test EC01 ném lỗi sau bước ghi trạng thái: không còn dòng nào.

Kiểm

  • pnpm nx run @sires/sample-service:test → đạt (cần Docker)
  • libs/ts/sample-service/src/sample.spec.ts › trạng thái, Audit Event và outbox cùng một giao dịch (PID-00006-AC01)
  • libs/ts/sample-service/src/sample.spec.ts › lỗi giữa giao dịch không để lại dòng nào (EC01)
  • pnpm nx run @sires/sample-service:lint, pnpm nx run @sires/sample-service:typecheck → đạt

Xong khi

  • Hai test trên đạt trên PostgreSQL 16 + pgvector thật, schema dựng bằng migration mẫu; service mẫu chỉ dùng API công khai của thư viện nền.
