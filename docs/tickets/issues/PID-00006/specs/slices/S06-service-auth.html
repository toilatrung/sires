Làm

  1. Thêm vào service mẫu một endpoint nội bộ (chỉ có trong service mẫu, không thêm vào hợp đồng) gắn service-auth guard của PID-00003; khai danh sách bên gọi được phép theo route bằng API của guard (guard không đọc hợp đồng, PID-00003 N2). Chỉ dùng API công khai của libs/ts/platform.
  2. Test phát token nội bộ bằng client và khóa ký của PID-00003 (khóa từ LocalKms của @sires/testing nếu thư viện cần), gọi endpoint: token hợp lệ của bên gọi được phép → đi qua; token sai chữ ký, hết hạn, hoặc thiếu header Authorization → 401 problem+json code = invalid_service_token, handler không chạy.
  3. Ghi cách gắn guard vào README của project (S01) để luồng service chép theo.
