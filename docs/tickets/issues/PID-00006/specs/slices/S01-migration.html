Làm

  1. Tạo project Nx libs/ts/sample-service/ (tạo mới): package @sires/sample-service (private), script build, typecheck, lint, test và tag Nx type:lib, lang:ts, scope:platform như libs/ts/testing/package.json; phụ thuộc bằng catalog: (NestJS, drizzle-orm, pg, @sires/platform; dev: drizzle-kit, @sires/testing, vitest, typescript). Không project nào khai báo phụ thuộc vào project này (H1). Gói chưa có trong catalog → dừng, báo PO (catalog thuộc luồng infra, quy tắc 1.4.7).
  2. Tạo migration đầu trong libs/ts/sample-service/migrations/ (tạo mới) bằng drizzle-kit dưới dạng custom migration SQL, giữ journal của drizzle-kit (kiến trúc 6.10, H6): chép phần chung của docs/database/ddl/00-common.sql (extension, schema app, replica, hàm và bảng nền tảng), rồi SQL của bảng mẫu — một bảng có account_id, row_version theo quy ước DDL, cuối file SELECT app.enable_tenant_rls() và SELECT app.grant_standard('<svc>', …) như file DDL của service. Migration không tạo vai trò. Tên service trong vai trò sires_<svc>_* do Dev đặt, ghi implement.md.
  3. Lệnh migrate: mã gọi migrate() của drizzle-orm trên thư mục migration, nhận chuỗi kết nối từ cấu hình; một target Nx riêng của project chạy lệnh này. Chỉ tiến: không viết migration đảo. Slice này không viết schema Drizzle bằng TypeScript (thuộc S02, D1). Service mẫu không deploy nên không có giá trị Helm migration.* (N10).
  4. Test libs/ts/sample-service/src/migration.spec.ts (tạo mới): startPostgres; test tạo vai trò _app, _system, _purge của service mẫu (database 3.2; D4, tới khi PID-00159 có) rồi chạy lệnh migrate lên database rỗng; kiểm bảng mẫu có RLS bật và ép, quyền của _app đúng grant_standard. EC08: không tạo vai trò → migration lỗi. EC09: chạy migrate lần hai → không áp lại migration nào, schema không đổi.
  5. Viết libs/ts/sample-service/README.md (tạo mới): cách thêm migration custom SQL mới, cách chạy target migrate, vai trò do ai tạo — để các luồng chép theo. File mới chạy node scripts/docs/add-license.mjs.

Kiểm

  • pnpm nx run @sires/sample-service:test → đạt (cần Docker)
  • libs/ts/sample-service/src/migration.spec.ts › áp lên database rỗng
  • libs/ts/sample-service/src/migration.spec.ts › thiếu vai trò thì migration lỗi (EC08)
  • libs/ts/sample-service/src/migration.spec.ts › chạy lại migrate không áp lại (EC09)
  • pnpm nx run @sires/sample-service:lint, pnpm nx run @sires/sample-service:typecheck → đạt; node scripts/docs/add-license.mjs --check → sạch
