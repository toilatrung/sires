Edge case

Đã quét theo nhóm: đồng thời và idempotency, sự kiện (trùng, đồng thời), phân quyền (khác tài khoản, token nội bộ), dữ liệu biên (thiếu ngữ cảnh tenant), dữ liệu cũ (database thiếu vai trò, migration chạy lại), tương thích nền tảng (DDL trên PostgreSQL 16), vận hành CI. Nhóm giao diện, agent, provider, phê duyệt, provenance không áp dụng.
