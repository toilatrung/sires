1. Ticket

  • Mục đích: Staging và production dựng từ cùng module. Viết trung lập nhà cloud để AQ-12 chưa trả lời vẫn tiến được (DLR-02).
  • Gồm: Khai báo giao diện module: Kubernetes, PostgreSQL, RabbitMQ, object storage, KMS, secret manager, gồm biến và đầu ra; envs/staging, envs/production gọi các module, chỉ có file biến mẫu.
  • Không gồm: Tài nguyên riêng của nhà cloud: chờ AQ-12, làm ở PID-00035; Áp dụng lên cloud thật (PID-00035, PID-00153); Backend lưu state: chờ AQ-12; Môi trường eval (PID-00113), load (PID-00134).
