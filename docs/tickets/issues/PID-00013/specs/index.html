5. Các bước thực hiện

  1. B1 Đọc docs/api-design/dist/openapi.bundled.yaml, @sires/contracts (PublicApi), client API và client SSE của PID-00012 — Kết quả: Danh sách operation, kiểu phản hồi — Kiểm tra: Khớp mục 2.3
  2. B2 Bộ sinh mock từ OpenAPI công khai: chọn operation, sinh handler và dữ liệu có type (ví dụ trong spec, không có thì theo schema) — Kết quả: Mock sinh ra typecheck đạt — Kiểm tra: pnpm nx run @sires/web:test
  3. B3 Cách bật mock khi chạy dev (mặc định tắt) và trong test; bản build production không có mock — Kết quả: Dev và test chạy được không cần gateway — Kiểm tra: pnpm --filter @sires/web dev với mock bật; pnpm nx run @sires/web:build
  4. B4 Mock mẫu cho /events — Kết quả: Client SSE của shell nhận sự kiện mẫu, nối lại theo Last-Event-ID — Kiểm tra: pnpm nx run @sires/web:test
  5. B5 Hướng dẫn cho khu vực: sinh mock vào apps/web/src/features/<khu vực>/__mocks__/, viết override có type — Kết quả: README của shell/mock — Kiểm tra: Đọc lại theo PID-00036, PID-00037
  6. B6 Viết test Vitest cho AC01 (đổi schema → sinh lại → typecheck báo chỗ lệch) — Kết quả: Test đạt — Kiểm tra: pnpm nx run @sires/web:test
