4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 8 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện

Phát qua outbox trong cùng giao dịch. Nghe qua inbox idempotent; bỏ bản cũ theo aggregate.version.

4.4. Quy tắc và trạng thái

  • Kích hoạt (APR-02), hàng đợi, hủy
  • Task Manual: nộp kết quả, checklist
  • Nhận workflow.* để chuyển T-05, T-06
  • Phát task.activated, task.activation_cancelled, task.status_changed
  • getTaskContextBundle

4.5. Giao diện

4.6. Agent và model
