2. Tiêu chí nghiệm thu

  • PID-00005-AC01 Given tài khoản A và B, When B truy vấn qua helper, Then không thấy dữ liệu của A; thiếu app.account_id thì 0 dòng.
  • PID-00005-AC02 Given API key trong log, When structlog ghi, Then giá trị bị che; lỗi không khai báo trả internal_error.
  • PID-00005-AC03 Given sự kiện do thư viện phát, When kiểm theo JSON Schema EventEnvelope (có aggregate bắt buộc), Then đạt; giao dịch rollback thì không có dòng outbox.
  • PID-00005-AC04 Given cùng một event id đến hai lần, When consumer xử lý trong giao dịch có inbox, Then tác động đúng một lần; Given helper upsert bảng replica nhận sự kiện có aggregate.version không lớn hơn source_version, Then bản replica không đổi. (H3)
  • PID-00005-AC05 Given token hết hạn, sai chữ ký, sub khác service ký, hoặc token agent không do orchestration ký hay có aud mảng không chứa service này, When gọi, Then 401 invalid_service_token; service ngoài x-callers thì 403 caller_not_allowed. (H2, H4)
  • PID-00005-AC06 Given cùng kịch bản (agent, bước), When gọi FakeModelGateway hai lần, Then kết quả giống nhau; tiêm rate_limited thì đếm đúng attempts.

  • H2 (cùng câu với PID-00003 H1): Token nội bộ được ký thế nào? → Đ: Mỗi service một cặp khóa ES256, kid = tên service, khóa trong KMS (test: khóa trong bộ nhớ); service ký lời gọi đi với sub = chính nó, bên nhận kiểm chữ ký theo kid và sub = service ký; token act.type = agent do orchestration phát (sub = agent-core, bắt buộc agentScope) chỉ nhận khi orchestration ký; endpoint x-apr chỉ nhận Researcher do gateway ký. Hạn ≤ 5 phút. · Ảnh hưởng: P3, S03, PID-00005-AC05, EC02, EC06, EC07, N4–N6
  • H3 (cùng câu với PID-00002, DBQ-04): Bỏ sự kiện có aggregate.version cũ đặt ở đâu? → Đ: Inbox chỉ lọc trùng theo (consumer, event_id); bỏ bản cũ bằng helper upsert bảng replica, chỉ ghi khi aggregate.version > source_version; không đổi DDL. EventEnvelope.aggregate thành bắt buộc (DBQ-04 đóng), nên hàm ghi outbox bắt buộc nhận aggregate. · Ảnh hưởng: P2, S02, PID-00005-AC03, AC04, EC04, EC05
  • H4 (cùng câu với PID-00003 H3, từ phiếu PID-00003 I2): Token Agent Run dùng cho nhiều service? → Đ: Token act.type = agent có aud là mảng các service Agent Run được đọc, bên nhận kiểm “aud chứa service này”; hạn vẫn ≤ 5 phút; orchestration trả token mới trong phản hồi heartbeatAgentRun, agent-core thay token. PO trong phiên, 11/11/2026. · Ảnh hưởng: P3, N5, S03, PID-00005-AC05, EC07
