4.4. Quy tắc và trạng thái

  • Tenancy, giao dịch, UUIDv7, lỗi problem+json cho FastAPI, logger structlog, OpenTelemetry
  • Outbox, inbox, idempotency, audit-emit với aio-pika
  • Service-auth guard và client token
  • Interface ModelGateway, FakeModelGateway, LocalKms, fixture pytest cho PostgreSQL, RabbitMQ, MinIO
  • Log bằng structlog, trace bằng OpenTelemetry; che dữ liệu như bản TS (kiến trúc 2.4, 10.3)
  • Consumer dùng aio-pika, ack thủ công (kiến trúc 2.4)
  • Vỏ sự kiện theo EventEnvelope (internal/schemas.yaml)
  • FakeModelGateway trả kịch bản ghi sẵn theo (agent, bước), tiêm lỗi theo mã chuẩn, đếm attempts (kiến trúc 8.9)
  • agent-core và knowledge cùng dùng interface ModelGateway (embedding qua thư viện dùng chung), nên interface đặt ở thư viện; adapter thật ở agent-core (kiến trúc 2.4, 8.1)
