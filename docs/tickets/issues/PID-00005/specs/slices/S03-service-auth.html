Làm

  1. Viết phần khóa: ký ES256 bằng khóa riêng của service mình, kid = tên service; tra khóa công khai theo kid từ bộ khóa của môi trường nạp khi khởi động; test sinh khóa trong bộ nhớ. Không gọi KMS thật
  2. Viết guard FastAPI kiểm JWT theo ServiceTokenClaims: chữ ký theo kid; sub = kid, trừ token act.type = agent phải do orchestration ký, sub = agent-core, có agentRunId và agentScope; iss; aud = service này, riêng token act.type = agent có aud là mảng và phải chứa service này (H4), token khác có aud mảng bị từ chối; exp còn hạn và ≤ 5 phút. Lỗi → 401 invalid_service_token; sub ngoài x-callers khai theo route → 403 caller_not_allowed
  3. Viết client phát token cho lời gọi đi: sub = service mình, aud = service đích, act lấy từ request đang xử lý; job và consumer dùng act.type = system. agent-core gọi service khác trong Agent Run bằng token orchestration đã cấp, không tự phát token agent; thay token khi phản hồi heartbeat trả token mới là việc của worker (PID-00073)
  4. Không làm luật route x-apr: không service Python nào có endpoint x-apr
