Bản tóm tắt theo spec-read-skill. Làm rõ 17/11/2026 theo lô PH-01; ngày 18/11/2026 PO chấp nhận đề xuất của chín phiếu I1–I9, đã gộp thành H1–H10 (trang ticket, mục 5); ngày 21/11/2026 PO trả lời phiếu I10 (cơ chế đánh dấu hoạt động), gộp thành H11. Còn ba slice chờ sửa nguồn (S11, S12, S14). Mỗi dòng dẫn nguồn.

Làm gì

Tác nhân là Researcher dùng SPA web. Shell là phần khung mọi khu vực dùng chung: TopBar, ProjectRail, routing theo IA PRD 4, token Cream và chuyển động, i18n vi/en, client API gọi gateway, client SSE /events, nhãn trạng thái chuẩn và trạng thái loading, empty, error. Sau làm rõ 18/11/2026 shell còn nối dữ liệu điều hướng, lưu ngôn ngữ vào Preferences, giữ nháp khi phiên hết hạn, cấp thẻ Interactive Agent Prompt, menu avatar với đăng xuất, và đánh dấu hoạt động của người dùng. Khu vực khác chỉ dùng shell qua API của nó (quy tắc 1.4.9, tickets 1.5), nên shell phải có trước để các khu vực làm song song.
