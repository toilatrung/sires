S04 — Client API và phiên

Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây. Sketch: designs/Shell-frame.html khối 8.

ACUX-AUTH-001-AC01 (phần shell)
Output specO1
Bước specB5; spec 4.7 (phiên hết hạn)
Edge caseEC02, EC07, EC08, EC09, EC10, EC11 (từ specs/scope.html)
Phụ thuộcS01

Làm

  1. Client API (tạo mới, ví dụ apps/web/src/shell/api/) dùng type PublicApi của @sires/contracts: gốc /api/v1, cookie cùng origin; lệnh ghi gửi X-CSRF-Token lấy từ GET /auth/session (EC09); hàm tạo và giữ Idempotency-Key theo thao tác để gửi lại dùng cùng khóa (EC10); trả ETag và nhận If-Match cho lệnh sửa.
  2. Lỗi: phản hồi application/problem+json thành lỗi có type theo Problem (code thuộc ErrorCode, errors[].code thuộc FieldErrorCode, correlationId); phản hồi không phải problem+json hay lỗi mạng thành lỗi chung nêu lỗi mạng hoặc mã HTTP, không giữ body thô (EC11).
  3. Phiên: khi tải ứng dụng gọi GET /auth/session; 401 → chuyển /sign-in kèm đường dẫn quay lại tương đối (EC07); có phiên → GET /me để lấy preferences.uiLanguage (EC02), chữ viết tắt avatar cho TopBar, và giữ ETag của lần đọc này cho S08 (H2). Không gọi GET /auth/session theo chu kỳ (an toàn với mọi phương án của I10).
  4. Mọi 401 unauthenticated khi đang dùng → một luồng “phiên hết hạn”: chuyển SignIn trạng thái session-expired, kèm đường dẫn quay lại (EC08). Tên tham số truyền sang SignIn ghi ở README của shell để PID-00036 dùng. Luồng này gọi kho nháp của S09 lưu nội dung các ô đã đăng ký trước khi chuyển (H7). Đánh dấu hoạt động của người dùng: S13 (H6, chờ I10).
  5. Test dùng stub fetch trong thư mục test của shell (quy tắc 1.4.4); không gọi gateway thật.

Kiểm

  • pnpm nx run @sires/web:test → đạt; pnpm nx run @sires/web:typecheck → đạt
  • apps/web/src/shell/session.spec.ts › chưa đăng nhập (UX-AUTH-001-AC01 phần shell; EC07); › ngôn ngữ theo Preferences (EC02); › phiên hết hạn (EC08)
  • apps/web/src/shell/api.spec.ts › csrf (EC09); › idempotency (EC10); › lỗi không phải problem (EC11); › problem có type

Xong khi

  • Khu vực khác gọi được API có type qua client của shell; chưa đăng nhập và phiên hết hạn đều về SignIn đúng trạng thái
