1. Ticket

  • Mục đích: Kiểm chứng ASM-04 và ADR-17: lắp context qua nhiều service có kịp và có vừa không. Kế hoạch ghi SPK-08 làm cùng orchestration; PID này giữ trong agent-core, dùng stub nội bộ có độ trễ để không chạm luồng khác.
  • Gồm: Dựng context mẫu theo 7 lớp PRD 14.2 cho project ở mức NFR-SCALE-001, dữ liệu tổng hợp; Đếm token từng lớp theo agent, so với context window model ứng viên của ba provider; Stub HTTP theo hợp đồng cho các API đọc context, có độ trễ cấu hình được; đo p95 khi đọc song song; Báo cáo: kích thước, độ trễ, kết luận sơ bộ ASM-04, đề xuất cho Context Assembler.
  • Không gồm: Context Assembler thật (PID-00072); Sửa apps/orchestration: spike không chạm luồng khác; Đặt ngưỡng độ trễ: PO quyết sau khi có số.
