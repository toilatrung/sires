4.4. Quy tắc và trạng thái

  • Dựng context mẫu theo 7 lớp PRD 14.2 cho project ở mức NFR-SCALE-001, dữ liệu tổng hợp
  • Đếm token từng lớp theo agent, so với context window model ứng viên của ba provider
  • Stub HTTP theo hợp đồng cho các API đọc context, có độ trễ cấu hình được; đo p95 khi đọc song song
  • Báo cáo: kích thước, độ trễ, kết luận sơ bộ ASM-04, đề xuất cho Context Assembler
  • Context gồm 7 lớp, cắt gọn theo thứ tự ưu tiên (PRD 14.2)
  • Đo trên project ở mức NFR-SCALE-001 (NFR-SCALE-001, NFR-SCALE-004)
  • Đo với context window của model từng provider (ASM-04)
  • Chưa có ngưỡng độ trễ: chỉ báo số, không tự đặt chỉ tiêu (spec-clarify-skill; kiến trúc chưa ghi ngưỡng)

4.6. Agent và model

Gọi model qua Model Gateway; prompt theo registry. Thay đổi prompt, định nghĩa agent thuộc NFR-EVAL-004. Agent không thực hiện được APR.
