Làm

  1. Cấu hình (tạo mới, ví dụ apps/planning/src/config/): chuỗi kết nối cho _app, _system, người chạy migration; đọc từ biến môi trường, kiểm khi khởi động; tên biến ghi README và implement.md.
  2. Module kết nối database qua helper tenancy của PID-00001, gắn vào apps/planning/src/app.module.ts (có sẵn); không viết repository nghiệp vụ.
  3. Lệnh migrate riêng của service trong image (H6; ví dụ src/migrate.ts → dist/migrate.js, script migrate) dùng hàm của S01 (migrate() của drizzle-orm, H1); đường dẫn thư mục migrations/ tính từ vị trí file build để chạy được trong image; không gọi drizzle-kit lúc chạy (EC25). Thêm migration.enabled: true, migration.command vào apps/planning/deploy/values.yaml (H6; tên khóa theo PID-00010 S02).
  4. Cập nhật apps/planning/README.md: entity sở hữu (ResearchPlan, PlanVersion, Phase, Task, TaskDefinition, TaskDependency, ReadinessResult, TaskReview; bảng kỹ thuật task_input_ref), bản sao chỉ đọc replica.project_state (nguồn project.lifecycle_changed của workspace, dùng cho tg_project_writable; consumer ở PID tính năng), chỗ khai báo state machine, bốn vai trò, biến cấu hình, cách chạy migration và test.
  5. Chạy migration trên PostgreSQL của pnpm local:up chỉ khi PID-00159 đã merge (compose tạo vai trò — H5); chưa thì ghi “chờ PID-00159” trong report.md, không tự tạo vai trò trên compose.
