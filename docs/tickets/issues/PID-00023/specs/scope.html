Edge case

Quét theo nhóm: trạng thái (chuyển sai theo 9.8 và 18.2, trạng thái cuối, cùng trạng thái, T-17); phê duyệt và điều kiện (guard, Workflow hoạt động); dữ liệu biên và ràng buộc 18.5; phân quyền (vai trò, khác tài khoản, project không Active); dữ liệu cũ, migration; môi trường (container, image, cache CI). Giao diện, provider, agent không áp dụng.
