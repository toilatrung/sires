S03 — Khung năm module con và interface engine

Nội dung
  • Làm
  • Kiểm
  • Xong khi

Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây. Không cần PID-00001 hay database.

ACPID-00019-AC02
Output specO2, O3
Bước specB3
Edge caseEC01 (từ specs/scope.html)
Phụ thuộc—

Làm

  1. Mỗi thư mục engine/, prompts/, context-store/, deliberation/, usage/ trong apps/orchestration/src/ (có sẵn, chỉ .gitkeep) có một Nest module rỗng và một index.ts là điểm vào duy nhất; xoá .gitkeep. Chú thích đầu module ghi phạm vi theo tickets 1.6 (engine: Workflow, Step, Checkpoint, heartbeat, sweeper, Recovery decision; prompts: InteractiveAgentPrompt, APR; context-store: ContextItem; deliberation: Deliberation, Board, Snapshot; usage).
  2. engine/index.ts xuất interface của engine (kiểu TypeScript và token tiêm phụ thuộc của Nest) mà module khác dùng; phương thức cụ thể do PID-00046 thêm. Không đặt logic, không truy cập database.
  3. AppModule (apps/orchestration/src/app.module.ts, có sẵn) nạp năm module, giữ HealthModule.
  4. Thêm luật lint trong thư mục của app (không sửa eslint.config.mjs ở gốc, luồng infra): file ngoài engine/ chỉ được import engine/index.ts, không import file khác trong engine/. Cách cài (ví dụ no-restricted-imports) Dev chọn, ghi ở implement.md.
  5. Test chứng minh luật bắt được vi phạm: chạy ESLint trên một đoạn mã mẫu import engine/ nội bộ từ prompts/ và thấy lỗi; đoạn mã import engine/index.ts thì không lỗi.

Kiểm

  • pnpm nx run @sires/orchestration:lint → đạt (không vi phạm trong mã thật)
  • pnpm nx run @sires/orchestration:test, pnpm nx run @sires/orchestration:build → đạt (cục bộ: pnpm --filter @sires/orchestration test, … build)
  • Test: apps/orchestration/src/engine/engine-boundary.spec.ts › luật chặn import nội bộ engine (PID-00019-AC02; EC01)
  • Test: apps/orchestration/src/app.module.spec.ts › nạp đủ module con (PID-00019-AC02; test /health có sẵn vẫn đạt)

Xong khi

  • Năm module nạp được trong AppModule; import nội bộ engine từ module khác làm lint lỗi; không còn .gitkeep ở năm thư mục
