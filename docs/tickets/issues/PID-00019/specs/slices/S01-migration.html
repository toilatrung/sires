Làm

  1. Viết migration đầu trong apps/orchestration/migrations/ (có sẵn, rỗng) theo quy ước D1 (H4, kiến trúc 6.10): một custom migration SQL của drizzle-kit (tạo bằng drizzle-kit generate --custom, kèm journal do công cụ sinh) chép từ docs/database/ddl/00-common.sql rồi orchestration.sql, giữ nguyên thứ tự và nội dung; chạy bằng migrate() của drizzle-orm (migrator node-postgres). Không viết schema Drizzle bằng TypeScript (PID tính năng, N6). Spec ghi tên NNN_init.sql: theo cách đặt tên của drizzle-kit, ghi tên thật ở implement.md.
  2. Bỏ khối INSERT INTO app.state_transition … của orchestration.sql: dòng chuyển trạng thái do S02 sinh từ khai báo (DEC-57), không chép tay. Trigger *_state vẫn tạo ở S01.
  3. Không tạo vai trò trong migration (database 3.2); lệnh app.grant_standard('orchestration') và REVOKE cuối file giữ nguyên nên cần vai trò có sẵn.
  4. Thêm phụ thuộc vào apps/orchestration/package.json bằng catalog:: drizzle-orm, pg là phụ thuộc chạy (S04 chạy migration trong image), drizzle-kit (dev). Dòng catalog do PID-00001 thêm (D5); chưa có trên main thì dừng slice, ghi “Bị chặn”, không tự thêm dòng catalog (quy tắc 1.4.7). pnpm-lock.yaml đổi nên check-tracks báo thêm luồng infra; ghi vào report.md.
  5. Viết test apps/orchestration/src/db/migration.spec.ts (tạo mới) dùng startPostgres của @sires/testing: tạo hai database rỗng và vai trò sires_orchestration_app, _system, _purge trong container (mã tạo vai trò nằm trong thư mục test của orchestration, dùng lại ở S04, S05; D4: test tự tạo vai trò tới khi PID-00159 có compose cục bộ); database A chạy migration bằng migrate(); database B chạy hai file DDL đọc từ docs/database/ddl/ (chỉ đọc). Bỏ dòng state_transition khỏi phép so ở slice này (S02 so riêng).
  6. So schema bằng một công cụ diff schema hoặc truy vấn catalog pg_catalog; Dev chọn công cụ, ghi ở implement.md. Phạm vi so theo PID-00019-AC01 trong specs/acceptance.html; bảng phiên bản của công cụ migration không tính (EC04); vector do helper tạo không được làm lệch phép so (EC05).
  7. DDL không chạy được trên PostgreSQL 16 thật (DDL mới chạy thử trên PGlite 17) → dừng, ghi “Cần PO” để PO mở DBQ; không tự sửa SQL so với DDL.
