4. Thiết kế kỹ thuật

4.1. Dữ liệu

Bảng ở mục 2.3, đúng DDL tham chiếu (DEC-57). Lệch thì ghi câu hỏi, không tự đổi schema. Migration theo kiến trúc 6.10 (H6); dòng app.state_transition sinh từ khai báo bằng helper của PID-00158, không chép tay (DR-01, H3). kek_version = id khóa KMS đã bọc DEK; tag GCM 16 byte nối cuối ciphertext (H4).
