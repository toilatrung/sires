Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

Phụ thuộcS01

Làm

  1. Cho Nx thấy phụ thuộc giữa project Python bằng plugin đăng ký trong nx.json (có sẵn): plugin cộng đồng cho uv workspace, hoặc plugin cục bộ đọc [tool.uv.sources] có workspace = true trong pyproject.toml của từng project; plugin cục bộ đặt trong thư mục luồng infra. Dev chọn, ghi lý do ở implement.md.
  2. Không sửa project.json, pyproject.toml của agent-core, knowledge, eval, sires-common (luồng khác). Không làm được bằng plugin → dừng, ghi “Cần PO”, đề xuất PID cho luồng app (EC05, N9).
  3. Khai pyproject.toml gốc, uv.lock, .python-version làm input cho target Python trong nx.json (named input hoặc targetDefaults), để đổi các file này làm mất cache cũ (EC06).
  4. Nếu thêm phụ thuộc gói ở package.json gốc: chạy lại pnpm install, không sửa tay pnpm-lock.yaml (quy tắc 1.4.7).

Kiểm

  • pnpm nx show projects --affected --files=libs/py/sires_common/src/sires_common/errors.py → đúng sires-common, agent-core, knowledge, eval (EC05)
  • pnpm nx show projects --affected --files=apps/knowledge/src → knowledge, eval; không có agent-core
  • pnpm nx run-many -t lint typecheck test --projects=tag:lang:python → đạt như trước khi sửa
  • Thao tác tay (EC06): trên nhánh cục bộ đổi line-length trong [tool.ruff] của pyproject.toml gốc, chạy pnpm nx run agent-core:lint → Nx không đọc từ cache; hoàn lại thay đổi
  • PR thử T2 vào develop (PID-00009-AC05, phần project): job Python chạy đúng bốn project, job TS skipped
  • node scripts/development/check-tracks.mjs → chỉ luồng infra

Xong khi

  • Đồ thị Nx có cạnh agent-core → sires-common, knowledge → sires-common, eval → agent-core, knowledge; AC05 phần project đạt trên T2; EC06 đạt
