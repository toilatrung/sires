Một lát dọc làm xong và kiểm được độc lập, trong đúng luồng của ticket. Trạng thái thực hiện ghi ở report.md của Dev, không ghi ở đây.

ACPID-00009-AC05 (phần build image)
Output specO1
Bước specB5; B9 (cache layer Docker)
Edge caseEC14 (từ specs/scope.html)
Phụ thuộcS01, S02 (để agent-core, knowledge được tính là bị ảnh hưởng)

Làm

  1. Job build image dạng matrix cho service bị ảnh hưởng có apps/<service>/deploy/values.yaml; chế độ toàn bộ build mọi service đó. Service TS dùng infra/docker/node/Dockerfile với SERVICE; agent-core, knowledge dùng infra/docker/python/Dockerfile với PACKAGE, MODULE (có sẵn). Đổi một Dockerfile chung → mọi service dùng nó (EC14); web không có image.
  2. Cache layer Docker bằng cache của GitHub Actions cho buildx.
  3. Không đăng nhập registry, không đẩy image, không thêm secret (N1, PID-00035).
  4. Không sửa Dockerfile ngoài phần cần cho CI build được; rà Dockerfile là việc của PID-00010.

Kiểm

  • PR thử T2 (sires_common): chỉ build image agent-core, knowledge (PID-00009-AC05, phần build image)
  • PR thử T3 (gateway): chỉ build image gateway
  • Script kiểm thay đổi với infra/docker/python/Dockerfile → image agent-core, knowledge; với infra/docker/node/Dockerfile → mười service TS có deploy/values.yaml (EC14)
  • Chạy lại T3 không đổi gì: bước build dùng cache layer (log buildx báo CACHED)
  • PR thử T1: job build image skipped

Xong khi

  • Image build đúng tập service ở T2, T3, T4; lần chạy lại dùng cache layer; không có bước đẩy image
