Làm

  1. Bộ kiểm payload dùng chung đọc schema message trong docs/api-design/events/asyncapi.yaml (và internal/schemas.yaml#/EventEnvelope), đặt trong thư mục luồng infra (H2).
  2. Job kiểm payload chạy target Nx kiểm payload do project tự khai, như S08: project bị ảnh hưởng có target (chế độ lọc) hoặc mọi project có target (chế độ toàn bộ); chưa có target thì chỉ chạy bộ tự kiểm và đạt (EC17); target thất bại → job thất bại, nêu project, message và trường (EC18).
  3. Bộ tự kiểm có một payload đúng và một payload sai (thiếu aggregate).
  4. README của thư mục bộ kiểm hướng dẫn luồng service tham gia: tên target, cách khai, nơi đặt mẫu payload trong thư mục project (quy tắc 1.4.4).

Kiểm

  • Bộ tự kiểm: payload sai (thiếu aggregate) → job thất bại, nêu message và trường; payload đúng → đạt (EC18)
  • T4 — CI của PR PID-00009 vào main: job kiểm payload chạy bộ tự kiểm, 0 project có target, đạt (EC17)
  • PR thử T1: job kiểm payload skipped
  • node scripts/development/check-tracks.mjs → chỉ luồng infra

Xong khi

  • Job kiểm payload chạy, chặn payload sai của bộ tự kiểm; README hướng dẫn tham gia có đủ để một luồng service tự thêm target
