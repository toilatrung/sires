  • Kiểm thay đổi trước (PO 12/11/2026): job đầu tiên so nhánh với merge-base của nhánh đích, xuất danh sách project Nx bị ảnh hưởng và nhóm thay đổi (TS, Python, hợp đồng docs/api-design, tài liệu, Dockerfile/Helm/Terraform, workflow và file dùng chung); các job khác đọc kết quả này
  • PR vào develop: job không liên quan tới thay đổi bỏ qua ngay trong PR đó bằng điều kiện if: ở mức job (job skipped được GitHub tính là đạt); nx affected chỉ chạy project bị ảnh hưởng; build image chỉ cho service bị ảnh hưởng
  • PR vào main và push vào main: chạy toàn bộ: mọi job, mọi project (nx run-many), vẫn dùng Nx cache cho task có input không đổi. Ở giai đoạn tài liệu mọi PR vào main nên đều chạy toàn bộ cho tới khi đóng OQ-111
  • Thời gian: hủy lần chạy cũ khi PR có push mới (concurrency, không áp cho push vào main); cache pnpm, uv, Nx và layer Docker; job độc lập chạy song song; mỗi job có timeout-minutes; ghi thời gian từng job vào job summary. Ngưỡng ngoài AC01 chốt sau khi có số đo (OQ-112)
