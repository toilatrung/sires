5. Các bước thực hiện

  1. B1 Nghe sandbox.build — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/sandbox-runner:test
  2. B2 Báo bắt đầu, kết quả qua API nội bộ manuscript — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/sandbox-runner:test
  3. B3 Trả sandbox.reply cho research — Kết quả: Quy tắc miền có test đơn vị — Kiểm tra: pnpm nx run @sires/sandbox-runner:test
  4. B4 Ghi sự kiện qua outbox trong cùng giao dịch — Kết quả: Không có trạng thái mà thiếu sự kiện — Kiểm tra: Test rollback
  5. B5 Viết consumer qua inbox, xử lý trùng và lệch thứ tự — Kết quả: Sự kiện xử lý đúng một lần — Kiểm tra: Test gửi lặp
  6. B6 Gọi luồng khác bằng client sinh từ hợp đồng; stub nằm trong thư mục test của luồng này — Kết quả: Không import mã service khác — Kiểm tra: Lint @nx/enforce-module-boundaries
  7. B7 Test tích hợp với Testcontainers — Kết quả: Tiêu chí nghiệm thu đạt — Kiểm tra: pnpm nx run @sires/sandbox-runner:test
