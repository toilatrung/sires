4.4. Quy tắc và trạng thái

  • Chạy openid-client với FakeOidcProvider: discovery, authorization code + PKCE, đọc claim, refresh, hết hạn token, RP-initiated logout, OIDC không khả dụng
  • Đối chiếu tài liệu của repo eTroy_OIDC: endpoint, scope, claim, hạn token, logout; ghi điểm khác stub
  • Báo cáo: phần đã kiểm trên stub, ASM-13 chưa kết luận, danh sách điểm kiểm lại cho PID-00038
  • Luồng authorization code + PKCE bằng openid-client, phiên server-side (ADR-09, ADR-27)
  • Liên kết tài khoản theo sub, lấy họ tên, email từ claim (ASM-13)
  • Chỉ đọc repo công khai toilatrung/eTroy_OIDC, không chạy và không sửa (H2)
