4. Thiết kế kỹ thuật

4.1. Dữ liệu

Bảng ở mục 2.3, đúng DDL tham chiếu (DEC-57). Lệch thì ghi câu hỏi, không tự đổi schema. Migration theo kiến trúc 6.10 (H5): custom migration SQL của drizzle-kit, chạy bằng migrate() của drizzle-orm, chỉ tiến; vai trò không nằm trong migration. CSRF token không lưu rõ: csrf_token_hash = sha256(HMAC-SHA256(khóa gateway, session id)) (H2).

4.2. API

Không có API mới. GET /auth/session (hiện thực ở PID-00038) được tính là thao tác người dùng và gia hạn phiên (H1).

4.3. Sự kiện

Không có sự kiện.

4.4. Quy tắc và trạng thái

  • Migration sires_gateway theo DDL, lệnh migrate và giá trị Helm migration.* (H4, H5)
  • Phiên server-side, hết hạn sau 12 giờ không hoạt động (ADR-27); gia hạn khi lệnh ghi được chấp nhận hoặc GET /auth/session (H1)
  • Cookie sires_session có Expires = absolute_expires_at (H3), kiểm X-CSRF-Token; token = HMAC-SHA256(khóa gateway, session id) (H2)
  • README ghi entity sở hữu

4.5. Giao diện

Không có giao diện.

4.6. Agent và model

Không gọi model trực tiếp.
