4.4. Quy tắc và trạng thái

  • Tenancy: helper chạy hàm trong giao dịch có SET LOCAL app.account_id, dùng Drizzle + node-postgres
  • Sinh UUIDv7; helper kiểm rowVersion theo If-Match, lệch trả 412
  • Bộ lọc lỗi application/problem+json cho adapter Fastify, mã lấy từ components/responses.yaml; kiểm tra đầu vào bằng Zod (nestjs-zod), lỗi schema trả validation_failed kèm errors[].field, errors[].code
  • Logger pino: che dữ liệu nhạy cảm, băm accountId, gắn mã tương quan
  • Khởi tạo OpenTelemetry cho HTTP, xuất qua index.ts
  • Truy cập database bằng Drizzle ORM + node-postgres; giao dịch đặt SET LOCAL app.account_id (kiến trúc 2.3; database 11)
  • Thiếu app.account_id thì RLS trả 0 dòng, an toàn mặc định (database 11)
  • Lỗi theo RFC 9457 với code ổn định (components/responses.yaml, NFR-OBS-005)
  • Log bằng pino, che chuỗi giống key (tiền tố ba provider, chuỗi entropy cao) và trường api_key, authorization; accountId trong log là giá trị băm có khóa (kiến trúc 10.3; NFR-OBS-001, NFR-OBS-002)
  • Kiểm tra đầu vào bằng Zod (nestjs-zod) (H2; kiến trúc 2.3)
  • Thư viện chỉ đổi tương thích ngược (quy tắc 1.4.5)
