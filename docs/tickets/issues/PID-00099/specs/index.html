4. Thiết kế kỹ thuật

4.1. Dữ liệu

Không có bảng mới.

4.2. API

Hiện thực đúng 3 operation ở mục 2.3. Lỗi theo components/responses.yaml; lệnh ghi có Idempotency-Key; cập nhật dùng If-Match.

4.3. Sự kiện
