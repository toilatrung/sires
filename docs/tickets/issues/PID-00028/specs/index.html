4.4. Quy tắc và trạng thái

  • Lập bộ mẫu từ nguồn truy cập mở, ít nhất 3 lĩnh vực, có công thức, bảng, hai cột, ảnh quét, file hỏng; chỉ commit danh sách URL
  • Trích xuất, đo chất lượng theo loại tài liệu, gồm thứ tự cột và vùng References
  • Đề xuất N và cách phát hiện lớp văn bản
  • Báo cáo kết luận ASM-06
  • pypdfium2 cho văn bản theo trang và phát hiện lớp văn bản; pdfplumber cho tọa độ từ (ADR-15; kiến trúc 7.2)
  • Có lớp văn bản: ≥ N ký tự/trang trên ≥ 80% trang; N chưa có số (kiến trúc 7.1)
  • ≤ 50 MB, ≤ 500 trang (INT-DOC-001; kiến trúc 7.1)
  • Bộ tài liệu mẫu đa ngành gồm PDF có lớp văn bản, PDF ảnh quét (PRD 19, Dữ liệu chuẩn)
