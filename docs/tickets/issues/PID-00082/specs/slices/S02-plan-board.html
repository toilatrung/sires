Làm

  1. /projects/:projectId/plan theo Plan: tiêu đề “Plan and Tasks”; bộ chọn Plan Version từ getPlan.versions (mới nhất trước, nhãn “vN · trạng thái”, baseline ghi “(baseline)”, Draft ghi “(đang soạn)”); mặc định baseline, chưa có baseline thì version mở kèm nhãn “Chưa duyệt” (EC02); chưa có Plan → trạng thái trống với “Yêu cầu Orchestrator đề xuất Plan” (requestPlanProposal) và liên kết Project AI Chat (EC01). Nút “So sánh version” tới màn so sánh.
  2. Chip Plan Version theo design.md §3: Proposed “Cần bạn xử lý”, Draft đề xuất viền đứt, Approved đã chốt, Superseded, Rejected trung tính (H4). Version Superseded, Rejected chỉ đọc, ghi lý do từ chối (EC03). Nhãn thảo luận theo provenance.deliberation (EC04).
  3. Khối “Nội dung Plan” thu gọn: mục tiêu, phương pháp, milestone, deliverable, rủi ro, giả định của version (getPlanVersion).
  4. Board: nhóm theo TaskStatus (thứ tự 9.8) kèm số; lọc Phase (phaseId), label (executionLabel), agent (proposedAgent, lọc trên mục đã tải) (EC05, EC06); thẻ: mã, tiêu đề, execution label có biểu tượng và chữ (component của shell), cờ needs review; bấm mở panel ?task=. Không kéo thả (EC07, EC08).
  5. Với version không phải baseline, board đọc định nghĩa của version, Task mới trong version ghi “mới trong vN”.
  6. SSE task.status_changed, plan_version.status_changed → đọc lại Task hoặc Plan (EC36). Project Archived: nút thay đổi vô hiệu kèm lý do (EC40).
