Làm

  1. Tạo migration đầu tiên trong apps/manuscript/migrations/ (có sẵn, rỗng) là custom migration SQL của drizzle-kit (drizzle-kit tạo file SQL rỗng và mục journal; tên file theo drizzle-kit) — H2, quyết định chung D1, kiến trúc 6.10: nội dung chép từ docs/database/ddl/00-common.sql rồi docs/database/ddl/manuscript.sql, trừ câu INSERT INTO app.state_transition (S02 sinh bằng helper). Giữ nguyên tên đối tượng, khóa ngoại hoãn, trigger, chính sách RLS, GRANT/REVOKE; không tạo vai trò. Không viết schema Drizzle bằng TypeScript (PID tính năng viết — N8). Chỉ tiến.
  2. Mã chạy migration trong apps/manuscript/src/db/ (tạo mới) bằng migrate() của drizzle-orm (node-postgres) và script migrate trong apps/manuscript/package.json (có sẵn), chạy được trong image không có drizzle-kit (PID-00010 EC01). Gói drizzle-orm, pg qua catalog:, drizzle-kit là devDependency qua catalog:; gói khác chưa có trong catalog thì dừng.
  3. Thêm vào apps/manuscript/deploy/values.yaml (có sẵn) khóa migration.enabled: true và migration.command = lệnh chạy mã migrate ở bước 2 trong image (H3, quyết định chung D3; Job migration của chart thuộc PID-00010 S02). Lệnh cụ thể ghi implement.md.
  4. Test tích hợp apps/manuscript/src/db/migration.spec.ts (tạo mới) với startPostgres của @sires/testing: tạo vai trò như database 3.2 (_system, _purge có BYPASSRLS; compose cục bộ chưa tạo tới khi có PID-00159 — H4); dựng database A bằng mã migrate của bước 2, database B bằng hai file DDL (bỏ phần INSERT chuyển trạng thái); so schema A và B — công cụ do Dev chọn (database 12.4 gợi ý migra), ghi implement.md.
  5. Test hành vi DDL cho EC02–EC13 trên database A bằng đúng vai trò (_app có SET LOCAL app.account_id, hoặc _system); mồi replica.project_state, replica.reference_state bằng _system; Manuscript và revision đầu tạo trong cùng giao dịch (khóa ngoại hoãn). Trong S01 bảng chuyển trạng thái còn rỗng nên mọi UPDATE đổi trạng thái đều bị từ chối — test EC09 kiểm đúng thông báo “lỗi thời” (trigger chấp nhận chạy trước trigger trạng thái).
  6. DDL lỗi trên PostgreSQL 16 mà không sửa được trong migration (EC01) → dừng, ghi đề xuất DBQ vào report.md.
