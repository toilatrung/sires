4.4. Quy tắc và trạng thái

  • Container helper cho PostgreSQL 16 + pgvector, RabbitMQ, MinIO
  • FakeOidcProvider: discovery, authorization code + PKCE, ID token ký bằng khóa test, refresh xoay vòng, RP-initiated logout, chế độ không khả dụng
  • Fake broker: gửi, nhận EventEnvelope, tiêm trùng và lệch thứ tự
  • FakeSourceAdapter theo kịch bản, tiêm lỗi
  • LocalKms: mã hóa, giải mã bằng khóa cục bộ
  • FakeSourceAdapter, FakeOidcProvider (ID token ký bằng khóa test), MinIO, LocalKms, RabbitMQ trong Testcontainers đặt ở libs/ts/testing và sires_common (kiến trúc 8.9)
  • FakeModelGateway là Python; service TypeScript dùng chế độ fake của agent-core (kiến trúc 8.9; kế hoạch mục 1.3 ghi chung, kiến trúc là chuẩn về cách hiện thực)
  • FakeOidcProvider bám luồng thật: authorization code + PKCE, /token, refresh token xoay vòng, claim sub, họ tên, email (ASM-13; repo công khai toilatrung/eTroy_OIDC)
