1. Ticket

  • Mục đích: Các luồng xây song song với stub cần fake dùng chung có hành vi xác định, để test không phụ thuộc dịch vụ ngoài (quy tắc 1.4.4). FakeOidcProvider cũng là stub OIDC mà PO chọn cho SPK-02.
  • Gồm: Container helper cho PostgreSQL 16 + pgvector, RabbitMQ, MinIO; FakeOidcProvider: discovery, authorization code + PKCE, ID token ký bằng khóa test, refresh xoay vòng, RP-initiated logout, chế độ không khả dụng; Fake broker: gửi, nhận EventEnvelope, tiêm trùng và lệch thứ tự; FakeSourceAdapter theo kịch bản, tiêm lỗi; LocalKms: mã hóa, giải mã bằng khóa cục bộ.
  • Không gồm: FakeModelGateway và mô hình Python (PID-00005); Chế độ fake của agent-core cho service TypeScript (PID-00070); Stub service gọi service: mỗi luồng tự viết ở thư mục test của mình.

  • PID-00004-AC01 Given container helper, When khởi động, Then có PostgreSQL 16 với extension vector ≥ 0.8, RabbitMQ, MinIO dùng được; xong thì được dọn.
