DEC-47Orchestrator remains the coordination model. An Analysis Agent is added (minimum two instances) that deliberates with the Orchestrator on options and solutions for problems the Orchestrator raises. Deliberation is a structured session, not free chat: independent sealed positions (round 1), cross-critique (round 2), an optional targeted round, then an Orchestrator synthesis that keeps disagreements and goes to the Researcher as a choice. Agents share context through a durable, append-only Deliberation Board and a shared Context Snapshot; the board also lets parallel steps use each other's intermediate findings without waiting, while official outputs rely only on final entries. Durable stores are the source of truth; any cache only accelerates. Open points: OQ-098–OQ-102.01/11/2026 · PO, phiên làm việc1.5, 2.1 (SCOPE-12–14), 3, 5.5, 6.3, 8.7, 14.9, 15.10, 16.6, 18, 19, 22
