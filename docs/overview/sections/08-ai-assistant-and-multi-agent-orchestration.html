8. Functional Requirements — AI Assistant and Multi-Agent Orchestration

Trạng thái biên soạn: Đã duyệt — bản cuối 31/10/2026 (phiếu chốt PC-01) · Cơ sở: outline đã chốt, mục 1–7, mục 21.1

Mục này đặc tả Orchestrator, bảy Specialist Agent, cách chuyển giao kết quả giữa agent, Interactive Agent Prompt, xử lý xung đột và lỗi, và giao diện model không phụ thuộc provider. Vai trò và quyền theo mục 3; danh sách agent theo SCOPE-14; entity theo 5.4 và 5.9. Priority do biên soạn đề xuất theo tiêu chí 2.4 (OQ-011) và được PO duyệt ngày 31/10/2026 (DEC-44, bảng tổng hợp ở mục 20). Phạm vi lấy từ outline và 21.1 (Confirmed); luồng, quy tắc và acceptance criteria là Assumption trừ khi ghi khác. Các câu hỏi đã đóng được ghi ở 8.7.

Mô hình điều phối

Orchestrator là điểm vào duy nhất từ chat tới các Specialist Agent. Specialist Agent không giao tiếp trực tiếp với nhau; mọi chuyển giao đi qua Orchestrator dưới dạng kết quả có cấu trúc và tham chiếu entity (8.3). System — không phải agent — thực hiện chuyển trạng thái, kiểm tra quyền, lưu checkpoint và ghi audit (3.4). Mỗi sự kiện điều phối (bắt đầu/kết thúc Agent Run, tool call, handoff, prompt, lỗi) được đẩy lên Agent Activity gần thời gian thực; MVP không streaming từng token đầu ra (chốt — biên soạn 30/10/2026; PO duyệt 31/10/2026, PC-01).

8.1. Orchestrator Responsibilities

Confirmed (outline): hiểu ý định người dùng, tạo plan, giao việc, đánh giá readiness và điều phối kết quả.

ORCH-INTENT-001 — Hiểu ý định và chọn hành động

Priority · ConfirmationP0 · Confirmed (outline)
PurposeChuyển tin nhắn tự nhiên thành một hành động được phép, rõ ràng và có thể kiểm tra.
ActorOrchestrator, System
PreconditionsOrchestrator có Agent Model Assignment hợp lệ.
TriggerMessage mới trong Global AI Assistant hoặc Project AI Chat.
Main Flow
  1. Orchestrator phân loại ý định thành một trong các nhóm: trả lời/giải thích, làm rõ ngữ cảnh (6.2), đề xuất hoặc sửa Plan (WF-01), yêu cầu thực thi Task (WF-02), tìm tài liệu (WF-04), tổng hợp/viết (WF-05), tạo sơ đồ (WF-07), điều hướng.
  2. Với hành động có tác động (tạo workflow, đổi dữ liệu), Orchestrator nêu rõ hành động sẽ làm và đối tượng trước khi System thực hiện.
  3. System kiểm tra hành động có thuộc danh sách được phép của Orchestrator (3.2) trong ngữ cảnh hiện tại.
Alternative / Error Flows
  • Ý định mơ hồ: hỏi lại bằng chat hoặc prompt choice.
  • Ý định là một hành động APR: Orchestrator không thực hiện; dẫn Researcher tới thao tác phê duyệt hoặc tạo prompt approval (PROMPT-APPROVAL-001).
  • Yêu cầu “chạy Task” khi Task chưa qua WF-02: khởi động readiness check, không kích hoạt.
Business RulesLời cho phép trong chat (“cứ làm đi”) không thay phê duyệt có cấu trúc (3.2). Ở Global AI Assistant chỉ có nhóm trả lời, điều hướng, tạo project, tra cứu Trusted Library (WS-CHAT-001).
Data & State ChangesAgent Run; có thể tạo Workflow, prompt.
Acceptance Criteria
  • ORCH-INTENT-001-AC01 Given Plan Version Proposed, When Researcher viết “duyệt plan đi” trong chat, Then Plan Version vẫn Proposed và Researcher được dẫn tới thao tác duyệt hoặc nhận prompt approval.
  • ORCH-INTENT-001-AC02 Given Task Ready, When Researcher yêu cầu chạy Task qua chat, Then readiness check (WF-02) được thực hiện và Task chỉ thành Queued sau xác nhận APR-02.
  • ORCH-INTENT-001-AC03 Given Global AI Assistant, When Researcher yêu cầu thực thi Task, Then không có Workflow nào được tạo.
Dependencies3.2, WS-CHAT-001, PROJ-CHAT-001
Open QuestionsOQ-007 (đã giải quyết)

ORCH-DELEGATE-001 — Giao việc và lắp ráp context

Priority · ConfirmationP0 · Confirmed (outline: delegate, route context)

Chốt (biên soạn 30/10/2026; PO duyệt 31/10/2026, PC-01): các bước không phụ thuộc nhau và không ghi cùng entity (ví dụ phân tích ở 6.3) được chạy song song; các bước còn lại chạy tuần tự.
Data & State ChangesWorkflow Step; Agent Run Pending → Running.
Acceptance Criteria
  • ORCH-DELEGATE-001-AC01 Given bước giao cho Writing Agent, When Agent Run được tạo, Then context chỉ chứa file bản thảo liên quan, claim và artifact Accepted, BibTeX của Trusted Reference; không chứa Discovered Result.
  • ORCH-DELEGATE-001-AC02 Given context vượt giới hạn model, When Agent Run được tạo, Then Agent Run ghi danh sách phần bị lược bỏ và hiển thị được ở Agent Activity.
  • ORCH-DELEGATE-001-AC03 Given Researcher đã khai báo lĩnh vực nghiên cứu nhưng chưa bật tùy chọn đưa vào context, When Agent Run được tạo, Then context manifest không chứa lĩnh vực nghiên cứu; sau khi bật, Agent Run tiếp theo chứa lĩnh vực nghiên cứu và không chứa trường cá nhân nào khác.
Dependencies3.3, 14.2, 14.3, AGENT-PROVIDER-001
Open QuestionsOQ-032, OQ-035 (đã giải quyết); OQ-015 (đã đóng 31/10/2026, PC-01)

AGENT-HANDOFF-001 — Handoff envelope

Priority · ConfirmationP0 · Confirmed (nguyên tắc), Assumption (cấu trúc)
PurposeKết quả giữa các bước truyền được, khôi phục được và truy vết được.
ActorSpecialist Agent, Orchestrator, System
PreconditionsAgent Run kết thúc Succeeded.
TriggerAgent trả kết quả.
Main Flow
  1. Agent trả handoff envelope: agentRunId, workflowStep, trạng thái kết quả (complete, partial, needs_input), tóm tắt ngắn, danh sách tham chiếu entity đã tạo (Artifact Version, Evidence, Claim, Change Proposal, Discovered Result), điểm chưa chắc chắn, đề xuất bước tiếp.
  2. System lưu entity trước, rồi lưu envelope và checkpoint.
  3. Bước tiếp theo nhận envelope và nạp entity theo tham chiếu, không nạp toàn bộ hội thoại của agent trước.
Alternative / Error Flowsneeds_input: Orchestrator tạo prompt information_request; Task → Waiting for User.
Business RulesEnvelope không chứa nội dung dài được nhúng thay cho tham chiếu entity. Envelope bất biến.
Data & State ChangesEntity đầu ra; handoff envelope; Checkpoint.
