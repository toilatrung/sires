SIRes — Thiết kế cơ sở dữ liệu (MVP)

Suy ra từ PRD SIRes v1.0 (mục 5, 14, 16, 18) và Architecture 0.2 (mục 3, 5, 6, 7, 10; ADR-03–ADR-06, ADR-22–ADR-24, ADR-28) · Khởi tạo: 02/11/2026 theo yêu cầu PO · Phiên bản 0.1 · PO duyệt 03/11/2026 (DEC-57)

Đã duyệt — PO 03/11/2026 (DEC-57). PO duyệt bộ tài liệu theo đề xuất. Quyết định thiết kế mang mã DBD-NN, DBD-01–DBD-13 Accepted; câu hỏi kỹ thuật DBQ-NN chờ Tech lead (mục 13). Khi tài liệu này khác PRD, kiến trúc hoặc đặc tả API, ba nguồn đó là chuẩn (README).

Tài liệu mô tả schema vật lý của SIRes trên PostgreSQL: mỗi service một database, bảng và cột của từng entity PRD 18.1, khóa và ràng buộc thực thi 18.5, state machine 18.2 ở mức database, bất biến và phiên bản 18.3, outbox/inbox/idempotency 18.4, Row-Level Security theo tài khoản, quyền theo vai trò, index cho chỉ tiêu hiệu năng 16.3–16.4, retention và purge 16.8. Kèm DDL tham chiếu chạy được trong thư mục ddl/ (danh sách file). Đối tượng: SWE viết migration và repository, GEN AI/AIE (knowledge, agent-core), QA viết test cách ly và dữ liệu mẫu, coding agent.
