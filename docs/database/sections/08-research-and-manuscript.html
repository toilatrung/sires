8.3. Thu hồi Reference và needs review

Consumer reference.status_changed.revoked (vai trò _system, một giao dịch): cập nhật replica.reference_state; evidence Active của Reference đó → Stale; Claim liên kết qua claim_evidence_link và đầu ra tìm qua provenance_input → needs_review = true kèm lý do; ghi inbox và outbox research.object_status_changed. Thay đổi phiên bản đầu vào khác (artifact version mới Accepted, context item Superseded) lan truyền cùng cách (9.11, 10.8).

8.5. Revision, Change Proposal, Build

  • Sửa trực tiếp hoặc chấp nhận proposal (một giao dịch): khóa hàng manuscript; INSERT revision mới (parent = current, tree mới); cập nhật manuscript_file; đổi current_revision_id; mọi proposal Proposed khác có base cũ → Outdated; outbox manuscript.object_status_changed.
  • Vì sao lưu tree: PRD chỉ yêu cầu changes; dựng lại cây của revision bất kỳ từ chuỗi changes cần đọc cả lịch sử (tới 2.000 revision, NFR-SCALE-001). Bản chụp path → sha256 làm build, so sánh và export đọc một dòng; kích thước nhỏ (200 file × ~100 byte). Trường tree đã thêm vào PRD 18.1 (DBD-09, DEC-57).
  • Build: manuscript tạo dòng Build rồi ghi outbox sandbox.build; sandbox-runner trả kết quả qua sandbox.reply; manuscript cập nhật trạng thái, log, PDF. Revision bị thay khi còn Queued → Failed (failure_reason = 'superseded').
