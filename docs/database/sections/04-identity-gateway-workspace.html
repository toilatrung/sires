  • Đăng nhập lần đầu: gateway gọi identity; identity sinh id, SET LOCAL app.account_id bằng chính id đó rồi INSERT (RLS WITH CHECK đạt). Tra tài khoản theo (issuer, subject) trước khi có tenant context dùng hàm app.find_account_by_identity (SECURITY DEFINER, chỉ trả id và status).
  • Xóa Provider Connection xóa luôn provider_secret (ON DELETE CASCADE). Điều kiện “không agent nào đang dùng trong Agent Run đang chạy” (18.2) kiểm qua API của orchestration trước khi xóa.
  • Yêu cầu xóa tài khoản (NFR-RET-004): trong một giao dịch, status → Deletion Requested, xóa mọi provider_secret của tài khoản, ghi outbox account.deletion_requested.
