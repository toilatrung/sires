Database orchestration là nguồn sự thật của workflow (ADR-03): khôi phục là đọc bảng, không replay sự kiện. Mọi chuyển trạng thái của engine khóa hàng workflow (SELECT … FOR UPDATE) trước khi ghi.

6.5. Usage

usage_ledger gộp một dòng cho mỗi Agent Run kết thúc và mỗi lô embedding do knowledge báo về (DBD-10), UQ (source, source_id), chỉ ghi thêm. Tổng hợp NFR-USAGE-002 theo project, Task, agent, Provider Connection, khoảng thời gian chạy trên một bảng; sai lệch 0 với tổng Agent Run vì dòng ghi trong cùng giao dịch kết thúc run. Provider không trả usage → unavailable = true, không ước tính (NFR-USAGE-001). Cách knowledge báo usage embedding: DBQ-03.
