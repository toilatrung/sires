7.2. Vòng đời Reference

  • Duyệt (APR-04): Pending Approval → Trusted kèm approval; outbox reference.status_changed.trusted → knowledge xếp job index.
  • Sửa metadata: INSERT reference_metadata_version (bản mới), cập nhật reference.metadata và metadata_version + 1 trong một giao dịch; outbox reference.metadata_updated.
  • DOI trùng: không chặn cứng (18.5) — truy vấn reference_doi_idx khi ghi để cảnh báo và đề xuất gộp; gộp đặt merged_into_id và chuyển selection sang bản giữ lại.
  • Thu hồi (APR-04): Trusted → Revoked kèm revocation.reason; mọi selection Active → Removed (System) trong cùng giao dịch; outbox cho knowledge (loại khỏi phạm vi), research (Evidence Stale), manuscript.
  • Xóa (NFR-RET-003): chỉ khi không còn selection Active ở project nào; xóa reference và lịch sử metadata; outbox reference.deleted. Reference còn được provenance hay Audit Event tham chiếu thì không xóa vật lý mà giữ trạng thái Revoked (OWN-05) — kiểm qua API research/manuscript trước khi xóa.

7.3. Tìm kiếm Trusted Library

NFR-PERF-002: ≤ 2 giây với 5.000 reference (OQ-031: chỉ tiêu đề, tên, metadata). search_tsv có trọng số A tiêu đề, B tác giả, C venue/DOI/BibTeX key, cập nhật bằng trigger vì unaccent không IMMUTABLE nên không dùng cột sinh được (DBD-11).

SELECT id, title, ts_rank(search_tsv, q) AS rank
FROM app.reference, websearch_to_tsquery('app.sires_simple', :text) q
WHERE account_id = app.current_account_id() AND search_tsv @@ q
UNION
SELECT id, title, similarity(title, :text)
FROM app.reference
WHERE account_id = app.current_account_id() AND title % :text      -- gõ sai, pg_trgm
ORDER BY rank DESC LIMIT 50;

7.5. Vector và truy xuất

  • Bảng theo model vì các model có số chiều khác nhau (DEC-31, kiến trúc 7.3). Thêm model = migration thêm dòng catalog, bảng và index. Danh mục model thật: DBQ-05. Ví dụ trong DDL: vec.emb_openai_text_embedding_3_small, 1.536 chiều.
  • Phạm vi bắt buộc (INT-VECTOR-001): reference_id IN (selection Active của project ∩ reference Trusted ∩ đã có vector của model hiện hành), tính từ bản sao, không nhận từ model.
WITH scope AS (
  SELECT s.reference_id FROM replica.project_reference_scope s
  JOIN replica.reference_state r USING (reference_id)
  WHERE s.account_id = app.current_account_id() AND s.project_id = :project
    AND s.status = 'Active' AND r.approval_status = 'Trusted')
SELECT v.chunk_id, v.embedding <=> :q AS distance
FROM vec.emb_openai_text_embedding_3_small v
JOIN app.chunk c ON c.id = v.chunk_id AND c.region = 'body'
WHERE v.account_id = app.current_account_id() AND v.reference_id IN (SELECT reference_id FROM scope)
ORDER BY distance LIMIT 50;    -- nhánh từ khóa: chunk_text.tsv, gộp RRF k = 60 ở ứng dụng

Phạm vi nhỏ (≤ ~50.000 chunk) quét chính xác qua index (account_id, reference_id); phạm vi lớn dùng HNSW với SET LOCAL hnsw.iterative_scan = relaxed_order. Ngưỡng chuyển và việc dùng halfvec do SPK-04 đo (kiến trúc 7.4).
