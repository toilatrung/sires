SIRes API — phạm vi MVP

Suy ra từ PRD SIRes v1.0 (PO duyệt qua phiếu chốt PC-01, 31/10/2026) · Khởi tạo: 31/10/2026 · Trạng thái: Assumption — đề xuất của biên soạn

Đặc tả REST cho giao diện web SIRes và các luồng WF-01–WF-07. Kế hoạch triển khai lập riêng, ngoài PRD (DEC-49); spec không gắn milestone. File gốc: openapi.yaml; bản gộp một file: dist/openapi.bundled.yaml; quy ước biên soạn: README.md.

Chưa phải quyết định kiến trúc. Technology stack và hạ tầng chưa chọn (DEC-27, OQ-091). Khi spec và PRD khác nhau, PRD là chuẩn. Spec đã qua redocly lint (hợp lệ, không lỗi).

Quy ước xuyên suốt

  • Xác thực: duy nhất qua eTroy OIDC; backend giữ token, client dùng cookie phiên sires_session và header X-CSRF-Token (INT-OIDC-001–004).
  • Ownership: tài nguyên cấp project nằm dưới /projects/{projectId}; tài nguyên của tài khoản khác trả 404 (OWN-01–03, NFR-ISOL).
  • Human-in-the-loop: APR-01–APR-10 là endpoint chỉ phiên Researcher gọi được, đánh dấu x-apr; agent chỉ tạo bản đề xuất (REL-04).
  • Chuyển trạng thái: endpoint hành động; chuyển ngoài bảng 18.2 trả 409 invalid_transition.
  • Idempotency và concurrency: Idempotency-Key cho lệnh có tác động; If-Match/ETag theo rowVersion.
  • Tác vụ dài: 202 Accepted + Workflow; cập nhật realtime qua SSE GET /events.
  • Bí mật: API key chỉ ghi vào, không bao giờ trả ra (keyHint ≤ 4 ký tự) (REL-07).

Hợp đồng nội bộ giữa các service
