SIRes làm context engineering bằng bốn việc

Write

Lưu thông tin ngoài cửa sổ context

  • Shared Context Store: quyết định, Plan, claim
  • Deliberation Board chỉ ghi thêm
  • Checkpoint sau mỗi bước

Select

Chỉ kéo vào phần liên quan

  • RAG trên Trusted Reference đã chọn
  • Handoff bằng tham chiếu entity
  • Đầu vào chính thức chỉ là bản Accepted

Compress

Giữ trong giới hạn token

  • 7 lớp ưu tiên, lớp 1–3 không cắt
  • Tóm tắt cuốn chiếu và 20 tin gần nhất
  • Phần bị cắt ghi vào manifest

Isolate

Mỗi phần một phạm vi riêng

  • Phạm vi đọc theo từng agent
  • Cách ly tài khoản, project ở tầng System
  • Context Snapshot cho mỗi phiên thảo luận

Mỗi Agent Run lưu context manifest: biết chính xác agent đã thấy entity nào, ở phiên bản nào.

Phân loại: LangChain, 07/2025. Cơ chế: PRD 14.1–14.5, 14.9; Architecture 5.10, 5.13.
