# Bản tóm tắt nghiệp vụ — khung

Trình bày trong phiên trước khi làm. Ngắn gọn; mỗi dòng dẫn nguồn (mã hoặc đường dẫn kèm anchor).

```
## TK-NNN — <tên> · Tóm tắt nghiệp vụ

Nguồn: ticket <đường dẫn> · spec <đường dẫn | chưa có> · luồng <service> · giai đoạn PH-NN · đọc lúc <dd/mm/yyyy>

### Làm gì
<2–4 câu: ai, khi nào, kết quả nghiệp vụ>

### Quy tắc
- <quy tắc> — <nguồn>
- Trạng thái và chuyển trạng thái: <…> — PRD 18.2
- Phê duyệt, provenance, cách ly context áp dụng: <…>

### Tiêu chí nghiệm thu
| AC | Kiểm bằng | Ghi chú |
| TK-NNN-AC01 | <file test › tên> | |

### Input đã kiểm
- <đường dẫn, hợp đồng, bảng DDL> — có / thiếu

### Output phải tạo
- O1 … O<n> theo spec (tóm tắt)

### Ngoài phạm vi
- …

### Mâu thuẫn, câu hỏi
- <đoạn A> ↔ <đoạn B> — đề xuất câu hỏi: …

### Cổng sẵn sàng
| Căn cứ | Spec | Phụ thuộc | Câu hỏi | Môi trường |
| đạt/chưa | … | … | … | … |

**Kết luận:** Sẵn sàng | Chưa sẵn sàng — <lý do> — <ai cần làm gì>
```
